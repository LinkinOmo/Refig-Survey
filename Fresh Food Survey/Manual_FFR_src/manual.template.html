1. วัตถุประสงค์

ก่อนปรับปรุงโซน Fresh Food ของสาขา ทีมโครงการต้องการข้อมูลจริงจากหน้างานจาก MTN เพื่อสรุปว่าตู้แช่แต่ละใบควร Refurbish / ใช้ต่อ (Workable) / ซื้อใหม่ (Request New) และ Rack เดิมยังใช้ต่อได้หรือไม่

สิ่งที่ MTN ต้องตรวจ (5 ข้อ):

  1. อุณหภูมิพื้นที่ขาย — ตู้ Plug-in / ตู้ Open ทำงานได้ดีเฉพาะเมื่อพื้นที่ขายไม่ร้อนเกิน
  2. ตู้แช่ทุกใบตามแผน — สรุปเป็น Refurbish / Workable / Request New
  3. Rack / Multiset / Cold room — สภาพ + รูปถ่าย
  4. ความพร้อมหน้างานสำหรับ Remote / Plug-in — ไฟ ท่อ ห้องเครื่อง จุดระบายน้ำ
  5. Final Layout — Layout ล่าสุดตรงกับหน้างานหรือไม่

หลักการ: ตรวจตามสภาพจริง ไม่ประเมินเกินหรือขาด · ถ่ายรูปทุกการ์ด · ตู้ / Rack ที่จะรื้อออกต้องมี Asset No.

1. ทำไมต้องตรวจ

โครงการ FF Renovation 2027: ปรับปรุงโซน Fresh Food {{NSTORE}} สาขา ตาม Master BOQ (ณ {{BOQ_AS_OF}}) ประมาณการรวม ≈ {{BOQ_M}} MB แต่งบที่ได้รับประมาณ 486 MB — ต้องตัดส่วนที่ไม่จำเป็นออกด้วยข้อมูลจริงจากหน้างาน

BOQ ทำจากโต๊ะ (Layout + อายุสาขา) ยังไม่มีใครยืนยันว่า ตู้ที่วางแผน Refurbish ทำได้จริงไหม ตู้ที่วางแผนซื้อใหม่ ยังใช้ต่อได้ไหม และ Rack เดิม ต้องเปลี่ยนจริงหรือไม่ (Rack Multiset เป็นหนึ่งในรายการที่มีมูลค่าสูงที่สุดใน BOQ)

สิ่งที่ทีมจัดซื้อ / ผู้ออกแบบต้องการจาก MTN (5 ข้อ):

  1. อุณหภูมิพื้นที่ขาย — ตู้ Plug-in / ตู้ Open ทำงานได้ดีเฉพาะเมื่อพื้นที่ขายไม่ร้อนเกิน
  2. ตู้แช่ทุกใบตาม BOQ — สรุปเป็น Final list: Refurbish / Workable / Request New
  3. Rack / Multiset / Cold room — สภาพ + รูปถ่าย เพื่อให้ทีมออกแบบตัดสินใจเปลี่ยน Rack หรือไม่
  4. ความพร้อมหน้างานสำหรับ Remote / Plug-in — ไฟ ท่อ ห้องเครื่อง จุดระบายน้ำ
  5. Final Layout — Layout ล่าสุดตรงกับหน้างานหรือไม่

หลักการ: ไม่ประเมินเกินหรือขาด · ถ่ายรูปทุกการ์ด · ตู้ / Rack ที่จะรื้อออกต้องมี Asset No. เพื่อเตรียม Write-off และขายซาก

3. ใครกรอก / เตรียมอะไร

  • ผู้กรอก: {{ROLES}} — ถ้าเป็นผู้รับเหมาให้ใส่ชื่อบริษัทด้วย
  • เตรียม: มือถือที่ล็อกอินแอป · เครื่องวัดอุณหภูมิ + ความชื้น · Final Layout ของสาขา (AMM MTN / ทีม HO เปิดดูในข้อ 2 ของฟอร์ม — MTN สาขาขอดูจาก AMM MTN) · ฟอร์มกระดาษ A4 ของสาขา — กด "🖨️ ฟอร์ม A4" ที่หัวแท็บหลังเลือกสาขา พิมพ์ไปจดหน้างาน แล้วให้ SGM ลงนาม (ต้องแนบรูปตอนส่ง) · ประวัติซ่อม CMS 12 เดือนของตู้ / Rack (ถ้ามี) · ทะเบียนทรัพย์สินสาขา (FAS) สำหรับ Asset No.
  • ข้อมูลแอร์ / ไฟฟ้า (ข้อ 6.2): หน้าจอ Chiller หรือ BMS ช่วงบ่าย · Nameplate / As-built แอร์ · ขนาดหม้อแปลง · มิเตอร์ MDB หรือแคลมป์มิเตอร์วัดกระแสช่วงพีค — ไม่ทราบเว้นว่างได้ (บังคับเฉพาะชนิดระบบแอร์)
  • เวลาที่ควรวัดอุณหภูมิ: ช่วงบ่ายที่ร้อนที่สุด (ประมาณ 13:00–16:00)
  • เวลา: ประมาณ 1.5–3 ชม. ต่อสาขา (ขึ้นกับจำนวนตู้) — ไม่ต้องทำให้จบในครั้งเดียว: ทุกข้อ (2–8) มีปุ่ม ☁️ บันทึกส่วนนี้ กดทีละข้อได้ ระบบส่งรูปของข้อนั้นขึ้นระบบทันที แล้วกลับมาทำต่อทีหลัง (เครื่องเดิมหรือเครื่องอื่น) ได้

🖨️ ฟอร์มกระดาษ A4 — ต้องให้ SGM ลงนาม แล้วแนบรูปในแอป (บังคับ) — กด "🖨️ ฟอร์ม A4" ที่หัวแท็บหลังเลือกสาขา (หรือหน้า ?page=ffr-checklist) ระบบใส่ข้อมูลของสาขาให้:

  • ตู้ตามแผน BOQ ทีละรายการ พร้อมรหัสอุปกรณ์ (เช่น FF-FRZ-06) และจำนวนแผน Refurbish / ซื้อใหม่ — มีช่องเขียน ตรวจพบ / Refurbish / Workable / Request New / ไม่พบ · สภาพ · Equipment ID · Asset No.
  • ตู้ / ระบบเดิมตามข้อมูลสัญญา PM — ตัวเลขที่ผู้รับเหมา PM นับไว้ (น้ำยา · คอมเพรสเซอร์ · ปีติดตั้ง Rack · ห้องเย็น · จำนวนตู้ Remote / Plug-in) พร้อมช่อง "นับได้จริง" ให้เขียนเทียบ
  • Rack ใบที่ 1–2 พิมพ์ค่าจาก PM ไว้ให้ — ติ๊ก ตรง หรือ ไม่ตรง แล้วเขียนค่าจริง
  • คำถามข้อ 6.1 – 6.3 แบบติ๊ก (คำตอบสีแดง = ความเสี่ยง / ข้อจำกัด) · อุปกรณ์ห้องเตรียม · ช่องลงชื่อ

ขั้นตอน: พิมพ์ฟอร์มของสาขา → จดหน้างาน → ให้ SGM ลงนามช่องท้ายฟอร์ม (รับทราบผลตรวจ) → ถ่ายรูปให้ชัด แนบใน ข้อ 8 ของแอป — ไม่แนบ ส่งไม่ได้ · ข้อมูลที่ใช้ในรายงานคือข้อมูลที่กรอกในแอป · เลือก "Save as PDF" ในหน้าพิมพ์ถ้าต้องการเก็บเป็นไฟล์

4.4 ตู้แช่ตาม BOQ (ข้อ 4) — หัวใจของแบบสำรวจ

5. กติกาแยกจำนวน Refurbish / Workable / Request New

ผลสรุปความหมายตัวอย่างผลต่องบ
🛠️ Refurbish ได้ปรับปรุงแล้วใช้ต่อได้จริง (เปลี่ยนคอยล์ / ฉนวน / ประตู / ไฟ / ทำสี)โครงสร้างแข็งแรง ระบบทำความเย็นยังทำอุณหภูมิได้ ขนาดตรง Layout ใหม่คิดราคา Refurbish ต่อใบ
✅ Workable (ใช้ต่อ)ใช้ต่อได้เลย ไม่ต้องทำอะไรตู้ค่อนข้างใหม่ สภาพดี ทั้ง 3 ด้าน0 ฿ — ลดงบได้มากที่สุด

⛔ ไม่พบ / ไม่มีตู้เดิมแผนระบุ แต่หน้างานไม่มีตู้นี้ (ถูกย้าย / ถอดไปแล้ว / เป็นจุดติดตั้งใหม่)— ใส่หมายเหตุไม่คิดงบ

10.4 เมื่อ BOQ เปลี่ยน (R1, R2…)

  1. รับไฟล์ Master BOQ ฉบับใหม่ ตั้งชื่อให้มี _R1 (หรือ R2…) — ระบบใช้ส่วนนี้เป็นชื่อรุ่น BOQ
  2. ผู้ดูแลระบบรันตัวแปลง BOQ แบบทดลองก่อน ได้ รายงานการเปลี่ยนแปลง: ประเภทตู้ที่เพิ่ม / หายไป · สาขาที่เพิ่ม / ถูกตัด · รายการที่เปลี่ยนจำนวนรายสาขา (เช่น "Suksawat · Low frozen L2500 Refurbish/New (12, 23) → (10, 25)")
  3. ตรวจรายงานแล้วจึงอนุมัติให้ใช้จริง → Deploy
  4. หลัง Deploy รายงานแสดงป้าย BOQ R0 ⚠ สีส้ม ที่สาขาซึ่งตรวจด้วย BOQ เก่า → ให้ Area MTN ตรวจเฉพาะรายการที่เปลี่ยน แล้วส่งสาขานั้นใหม่

ผลตรวจที่ส่งแล้วไม่เสียหายเมื่อ BOQ เปลี่ยน: ประเภทตู้เดิมคงรหัสเดิมเสมอ ประเภทใหม่ต่อท้าย ประเภทที่ถูกตัดยังอยู่ให้รายการเก่าอ้างถึงได้ · การ์ดแต่ละใบจำชื่อตู้ไว้ด้วย — ถ้ารหัสกับชื่อไม่ตรงกัน ระบบหาตามชื่อ · ถ้าประเภทนั้นไม่มีใน BOQ แล้ว การ์ดยังคงชื่อเดิม (ไม่มีราคา) ไม่ถูกเปลี่ยนเป็นตู้ชนิดอื่น · ทุกรายการบันทึกคอลัมน์ BOQ Rev (เช่น R0 · 2026-11-15) — ดูได้ใน Export Excel

  • ในแบบสำรวจ FF Renovate ช่อง Equipment ID ไม่บังคับ · รายการให้เลือกมาจากแบบสำรวจตู้แช่ / อุปกรณ์ FF ล่าสุดของสาขา — สาขาที่ยังไม่เคยทำแบบสำรวจนั้นจะไม่มีรายการ (ยังพิมพ์ / สแกนได้)
  • รายงาน: แสดง Equipment ID ในรายละเอียดการ์ด และคอลัมน์ Equipment IDs ในชีต Cabinets

10.6 เครื่องมืออื่นของ Super Admin

  • 🖨️ ฟอร์มกระดาษ A4 (?page=ffr-checklist) — เลือกสาขาแล้วระบบใส่รายการตู้ตามแผน BOQ ให้ (ไม่มีราคา) หรือพิมพ์ฟอร์มเปล่า · หัวแท็บแบบสำรวจมีปุ่ม 🖨️ ฟอร์ม A4 ของสาขาที่เลือก
  • 🔒 คู่มือฉบับเต็ม — ลิงก์เปิดได้ 12 ชั่วโมงต่อครั้ง ห้ามส่งต่อ · ผู้ใช้ทั่วไปใช้ ?page=ffr-manual
  • 📦 รวมข้อมูล Archive (ปุ่มมุมซ้ายล่าง) — รวมรายการเก่าที่ย้ายไปเก็บใน Drive แล้ว
  • ลบรายการ — ในหน้ารายละเอียด (Super Admin / Schedule Admin) ใช้กับรายการที่ส่งผิด · รายงานใช้รายการล่าสุดของแต่ละสาขาเสมอ
  • อีเมลติดตามงาน — ระบบติดตามทางอีเมล (SGM / AMM MTN) ปัจจุบันครอบคลุมแบบสำรวจ Hyper 8 แบบ + Fixed Asset · ยังไม่รวม FF Renovate

BOQ บอก 8 ใบ แต่หน้างานมี 6 ใบ?ใส่จำนวนที่ตรวจ = 8 แล้วแยก 2 ใบเป็น "ไม่พบ" (เขียนหมายเหตุ) — หรือถ้าตู้จริงต่างรุ่น ให้เพิ่มการ์ด "ตู้ที่พบ" แยก
ตู้เดียวกันแต่สภาพต่างกัน ทำอย่างไร?การ์ดเดียวแยกจำนวนได้ เช่น 6 ใบ = Refurbish 4 + Workable 1 + Request New 1 · ประเมินสภาพตามภาพรวมของรายการ และเขียนใบที่แย่ในหมายเหตุ
ไม่มีเครื่องวัดความชื้น?ใส่เฉพาะ °C ได้ (%RH เว้นว่าง) แต่ต้องวัดอย่างน้อย 3 จุดและแนบรูปเครื่องวัด
ไม่รู้ Asset No.?เว้นว่างได้ — แต่ต้องเลือกประเภทตัดจำหน่าย และถ่ายรูปตู้ / Nameplate ไว้ ทีม HO จับคู่กับทะเบียน FAS ภายหลัง
สาขานี้ไม่มี Rack (ตู้ Plug-in ทั้งหมด)?ไม่ต้องเพิ่มการ์ด Rack — ตอน Submit ระบบจะถามยืนยันว่าสาขาไม่มี Rack / Multiset / Cold room
ส่งไปแล้ว อยากแก้ไข?ส่งแบบสำรวจของสาขาเดิมใหม่ได้ — รายงานใช้รายการล่าสุดของแต่ละสาขาเสมอ · รายการเก่าที่ส่งผิดให้แจ้ง Admin ลบ
ขึ้น 🔒 "เปิดได้เฉพาะ AMM MTN ของสาขาและทีม HO"?ไฟล์ Layout เป็นความลับของโครงการ — ขอดูจาก AMM MTN ตอนลงพื้นที่ แล้วเลือกสถานะ Final Layout ตามที่เห็น · ถ้าคุณเป็น AMM MTN ของสาขานั้นแต่ยังขึ้น 🔒 ให้แจ้ง HO ตรวจอีเมลในฐานข้อมูล
SGM ไม่อยู่สาขาวันที่ตรวจ ยังไม่ได้ลายเซ็น?กรอกทุกข้อแล้วกด Save Draft ไว้ก่อน — เมื่อ SGM ลงนามแล้วจึงถ่ายรูปฟอร์ม แนบในข้อ 8 แล้วกด Submit (ทำต่อจากเครื่องอื่นได้)
ไม่เห็นไฟล์ Final Layout ของสาขา?เลือก "ยังไม่ได้รับ Final Layout" แล้วตรวจต่อ · แจ้ง HO ให้วางไฟล์ในโฟลเดอร์ Layout และกดสแกน
