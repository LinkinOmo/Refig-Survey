🎯 LP แจ้งอุปกรณ์ เสีย / รอซ่อม ไว้ — ส่วนใหญ่รอ MTN สรุปว่า "ซ่อมได้" หรือ "ต้องซื้อใหม่" แบบสำรวจนี้ใช้ยืนยันที่หน้างานทีละกลุ่มอุปกรณ์ แล้วงานจะเข้า OPEX (ซ่อม) หรือ CAPEX LP (ซื้อใหม่) ได้ทันที

📋 เลือกสาขาแล้วระบบจะดึง รายการเสียจาก LP + งาน CMS (CCTV / EAS) ของสาขามาให้ · เปิด CMS ใหม่ เฉพาะรายการที่ต้องซ่อม/เปลี่ยนจริง แล้วกลับมาใส่เลข CMS ในรายงาน

💰 ซ่อมทั่วไปไม่เพิ่มทรัพย์สิน ≤ 5,000 ฿ = OPEX · ซื้ออุปกรณ์ใหม่ (กล้อง / DVR / UPS / จอ) = CAPEX — แยก ค่าอุปกรณ์ / ค่าแรง / ค่าปีนป่าย / ค่าทดสอบ

3. เกณฑ์ตรวจเช็กระบบ (OK / NG / ไม่มี)

ตรวจทุกข้อ · NG = ไม่ผ่าน ให้เพิ่มเป็นการ์ดในข้อ 4 ด้วย · ไม่มี = สาขาไม่มีอุปกรณ์นั้น

4. ผลตรวจอุปกรณ์เสีย (การ์ดทีละกลุ่ม)

1 การ์ด = อุปกรณ์ชนิดเดียวกัน อาการเดียวกัน — แยกจำนวนเป็น ใช้งานได้แล้ว / ซ่อมได้ / ต้องเปลี่ยนใหม่ / ไม่พบ-ยกเลิกใช้งาน ให้ครบจำนวน · การ์ดที่ ซ่อม / เปลี่ยน ต้องมีรูป
