แบบฟอร์มนี้ใช้บันทึกหน่วยการใช้ไฟฟ้าจากมิเตอร์ EDMI ของระบบ Solar Rooftop ประจำสาขา — กรอกผ่านแอป Mini Big C Maintenance แท็บ “☀️ EDMI Solar Meter”

📋 ขั้นตอนการเก็บข้อมูลหน้างาน

  1. 1ถ่ายภาพนิ่ง หน้าจอมิเตอร์ด้วยมือถือ ให้เห็น Code และตัวเลขชัดเจน ครบทั้ง 4 Code (000-003)
  2. 2อัดวิดีโอ กดวนดูครบทุก Code ตั้งแต่ 000 ถึง 003 ในคลิปเดียว (ใช้เป็นหลักฐานสำรอง หากภาพนิ่งไม่ชัดหรือมีข้อโต้แย้งภายหลัง) — เก็บคลิปไว้ที่เครื่อง ไม่ต้องอัปโหลดเข้าแอป
  3. 3กรอกตัวเลข ที่อ่านได้ลงในแบบฟอร์ม และอัปโหลดภาพถ่าย (จากข้อ 1) แนบทุก Code แล้วกด Submit

1. รู้จักมิเตอร์ของสาขาคุณ ก่อนเริ่ม

มิเตอร์ EDMI มี 3 รุ่น ปุ่มกดเลื่อนหา Code จะอยู่ตำแหน่งเดียวกันในทุกรุ่น — สาขาส่วนใหญ่ใช้รุ่นตามขนาดร้านดังนี้

003 kWh Rate C — วันหยุด 00:00–24:00 เสาร์-อาทิตย์และวันหยุด

⚠️ ช่วงเวลาในตารางด้านบนคือช่วงที่มิเตอร์ใช้ "สะสม" ค่าไฟของ Code นั้นๆ ไว้ ไม่ใช่เวลาที่ต้องไปอ่านค่า — สามารถกดดูและถ่ายภาพทั้ง 4 Code ได้ทุกเมื่อในช่วงเวลาที่กำหนด (11.00-12.00 น.) โดยไม่ต้องรอให้ถึงช่วงเวลาที่ระบุในตาราง

กดปุ่มเลื่อนบนมิเตอร์ให้ตัวเลข Code ที่มุมจอตรงกับตารางด้านบน แล้วอ่านตัวเลขหน่วย (kWh) ที่แสดงอยู่ — ถ่ายภาพหน้าจอให้เห็น ทั้ง Code และตัวเลข ในภาพเดียวกันเสมอ

🔴 บังคับกรอก: ต้องใส่ทั้งตัวเลขและรูปถ่ายให้ครบทั้ง 4 Code ระบบจะไม่ให้กด Submit ผ่านหากขาดรายการใดรายการหนึ่ง — ยกเว้นกรณีเข้าถึงมิเตอร์ไม่ได้ (ดูหัวข้อที่ 3)

3. กรณีตู้ควบคุมมิเตอร์ถูกล็อค Access Blocked

ถ้าไปถึงหน้างานแล้วเปิดตู้ควบคุมมิเตอร์ไม่ได้จริงๆ (ถูกล็อคกุญแจ ไม่มีผู้ถือกุญแจ ตู้ชำรุด หรือช่างไฟฟ้ายังไม่มาเปิดให้) ระบบมีทางเลือกให้ส่งข้อมูลได้โดยไม่ต้องมีตัวเลข Code — อยู่ในส่วนที่ 3 ของฟอร์ม เหนือช่องกรอก Code ทั้ง 4

🔒 ไม่สามารถอ่านค่าได้ (ตู้ควบคุมมิเตอร์ถูกล็อค / เข้าถึงไม่ได้)

ติ๊กช่องนี้เมื่อเข้าถึงมิเตอร์ไม่ได้จริงเท่านั้น — เมื่อติ๊กแล้วระบบจะทำงานดังนี้:

  • ช่องกรอกตัวเลข Code 000-003 จะถูกปิดใช้งานและไม่บังคับกรอกอีกต่อไป
  • ต้องกรอกรายละเอียดปัญหา (เช่น ตู้ล็อคกุญแจ ไม่มีผู้ถือกุญแจ / ตู้ชำรุดเปิดไม่ได้ / ช่างไฟฟ้ายังไม่มาเปิด) — เป็นข้อความบังคับ
  • ต้องแนบภาพถ่ายหลักฐานของตู้ที่ล็อคหรือเข้าถึงไม่ได้ — เป็นภาพบังคับ
  • อีเมลยืนยันที่ส่งออกจะแสดงกรอบสีแดง "🔒 ไม่สามารถอ่านค่าได้" พร้อมเหตุผลและภาพแทนตารางตัวเลข Code

ใช้เฉพาะกรณีจำเป็นจริงๆ — ไม่ใช่ทางลัดเพื่อข้ามการอ่านค่า หากเปิดตู้ได้ในภายหลัง ให้กลับมาอ่านค่าและส่งฟอร์มใหม่อีกครั้ง พร้อมแจ้งผู้เกี่ยวข้องให้มาเปิดตู้สำหรับรอบถัดไป

4. ข้อควรระวัง

✅ ทำแบบนี้
  • ถ่ายภาพให้เห็น Code และตัวเลขชัดเจนในภาพเดียว
  • กรอกครบทั้ง 4 Code ทุกครั้งที่อ่านค่า แม้ตัวเลขจะใกล้เคียงกับครั้งก่อน
  • ส่งข้อมูลภายใน 15:00 น. ของวันเดียวกัน
  • ตรวจสอบชื่อ-รหัสสาขาที่ระบบเลือกให้ก่อนกด Submit
  • ถ้าตู้ควบคุมล็อคจริง ให้ใช้ช่อง "🔒 ไม่สามารถอ่านค่าได้" แทนการปล่อยว่างหรือกรอกตัวเลขมั่ว
⚠️ อย่าทำแบบนี้
  • อย่าประมาณตัวเลขจากความจำ ต้องอ่านจากหน้าจอมิเตอร์จริงเท่านั้น
  • อย่าข้าม Code 003 (Holiday) เพียงเพราะตัวเลขเปลี่ยนน้อย
  • อย่าใช้ภาพถ่ายเก่าจากครั้งก่อน
  • อย่าปล่อยชื่อผู้แจ้งเป็นชื่อสาขาแทนชื่อคน
  • อย่าติ๊ก "เข้าถึงไม่ได้" เพื่อความสะดวก ทั้งที่จริงเปิดตู้ได้
