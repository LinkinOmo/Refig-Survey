1. วัตถุประสงค์

ก่อนปรับปรุงโซน Fresh Food ของสาขา ทีมโครงการต้องการข้อมูลจริงจากหน้างานจาก MTN เพื่อสรุปว่าตู้แช่แต่ละใบควร Refurbish / ใช้ต่อ (Workable) / ซื้อใหม่ (Request New) และ Rack เดิมยังใช้ต่อได้หรือไม่

สิ่งที่ MTN ต้องตรวจ (5 ข้อ):

  1. อุณหภูมิพื้นที่ขาย — ตู้ Plug-in / ตู้ Open ทำงานได้ดีเฉพาะเมื่อพื้นที่ขายไม่ร้อนเกิน
  2. ตู้แช่ทุกใบตามแผน — สรุปเป็น Refurbish / Workable / Request New
  3. Rack / Multiset / Cold room — สภาพ + รูปถ่าย
  4. ความพร้อมหน้างานสำหรับ Remote / Plug-in — ไฟ ท่อ ห้องเครื่อง จุดระบายน้ำ
  5. Final Layout — Layout ล่าสุดตรงกับหน้างานหรือไม่

หลักการ: ตรวจตามสภาพจริง ไม่ประเมินเกินหรือขาด · ถ่ายรูปทุกการ์ด · ตู้ / Rack ที่จะรื้อออกต้องมี Asset No.

3. ใครกรอก / เตรียมอะไร

  • ผู้กรอก: MTN สาขา · AMM / Area MTN · ทีม MTN HO · ผู้รับเหมา (Vendor) · อื่นๆ — ถ้าเป็นผู้รับเหมาให้ใส่ชื่อบริษัทด้วย
  • เตรียม: มือถือที่ล็อกอินแอป · เครื่องวัดอุณหภูมิ + ความชื้น · Final Layout ของสาขา (AMM MTN / ทีม HO เปิดดูในข้อ 2 ของฟอร์ม — MTN สาขาขอดูจาก AMM MTN) · ฟอร์มกระดาษ A4 ของสาขา — กด "🖨️ ฟอร์ม A4" ที่หัวแท็บหลังเลือกสาขา พิมพ์ไปจดหน้างาน แล้วให้ SGM ลงนาม (ต้องแนบรูปตอนส่ง) · ประวัติซ่อม CMS 12 เดือนของตู้ / Rack (ถ้ามี) · ทะเบียนทรัพย์สินสาขา (FAS) สำหรับ Asset No.
  • ข้อมูลแอร์ / ไฟฟ้า (ข้อ 6.2): หน้าจอ Chiller หรือ BMS ช่วงบ่าย · Nameplate / As-built แอร์ · ขนาดหม้อแปลง · มิเตอร์ MDB หรือแคลมป์มิเตอร์วัดกระแสช่วงพีค — ไม่ทราบเว้นว่างได้ (บังคับเฉพาะชนิดระบบแอร์)
  • เวลาที่ควรวัดอุณหภูมิ: ช่วงบ่ายที่ร้อนที่สุด (ประมาณ 13:00–16:00)
  • เวลา: ประมาณ 1.5–3 ชม. ต่อสาขา (ขึ้นกับจำนวนตู้) — ไม่ต้องทำให้จบในครั้งเดียว: ทุกข้อ (2–8) มีปุ่ม ☁️ บันทึกส่วนนี้ กดทีละข้อได้ ระบบส่งรูปของข้อนั้นขึ้นระบบทันที แล้วกลับมาทำต่อทีหลัง (เครื่องเดิมหรือเครื่องอื่น) ได้

🖨️ ฟอร์มกระดาษ A4 — ต้องให้ SGM ลงนาม แล้วแนบรูปในแอป (บังคับ) — กด "🖨️ ฟอร์ม A4" ที่หัวแท็บหลังเลือกสาขา (หรือหน้า ?page=ffr-checklist) ระบบใส่ข้อมูลของสาขาให้:

  • ตู้ตามแผน BOQ ทีละรายการ พร้อมรหัสอุปกรณ์ (เช่น FF-FRZ-06) และจำนวนแผน Refurbish / ซื้อใหม่ — มีช่องเขียน ตรวจพบ / Refurbish / Workable / Request New / ไม่พบ · สภาพ · Equipment ID · Asset No.
  • ตู้ / ระบบเดิมตามข้อมูลสัญญา PM — ตัวเลขที่ผู้รับเหมา PM นับไว้ (น้ำยา · คอมเพรสเซอร์ · ปีติดตั้ง Rack · ห้องเย็น · จำนวนตู้ Remote / Plug-in) พร้อมช่อง "นับได้จริง" ให้เขียนเทียบ
  • Rack ใบที่ 1–2 พิมพ์ค่าจาก PM ไว้ให้ — ติ๊ก ตรง หรือ ไม่ตรง แล้วเขียนค่าจริง
  • คำถามข้อ 6.1 – 6.3 แบบติ๊ก (คำตอบสีแดง = ความเสี่ยง / ข้อจำกัด) · อุปกรณ์ห้องเตรียม · ช่องลงชื่อ

ขั้นตอน: พิมพ์ฟอร์มของสาขา → จดหน้างาน → ให้ SGM ลงนามช่องท้ายฟอร์ม (รับทราบผลตรวจ) → ถ่ายรูปให้ชัด แนบใน ข้อ 8 ของแอป — ไม่แนบ ส่งไม่ได้ · ข้อมูลที่ใช้ในรายงานคือข้อมูลที่กรอกในแอป · เลือก "Save as PDF" ในหน้าพิมพ์ถ้าต้องการเก็บเป็นไฟล์

4.2 แผน BOQ & Final Layout ของสาขา (ข้อ 2)

กล่องสีฟ้า 📋 ตู้ / ระบบเดิมตามข้อมูลสัญญา PM (ใต้ Layout) แสดงสิ่งที่ผู้รับเหมา PM นับไว้ของสาขานี้: น้ำยา · คอมเพรสเซอร์ Rack · ปีติดตั้ง Rack · ห้องเย็น · จำนวนตู้ Remote / Plug-in (High Frozen · Low Frozen · Drum · Stainless) — ใช้เทียบหน้างาน ถ้าไม่ตรงให้กรอกตามที่เห็นจริง · บรรทัดสีส้มคือข้อสังเกต เช่น BOQ วางแผน Refurbish มากกว่าที่ PM นับได้ หรือ Rack R22 อายุเกิน 15 ปี

4.3 อุณหภูมิพื้นที่ขาย (ข้อ 3)

เกณฑ์อ้างอิงตู้ Climate Class 3 = 25 °C / 60 %RH · เกณฑ์ "ร้อนเกิน > 27 °C" เป็นฉบับร่าง รอยืนยันกับผู้ผลิตตู้ — สาขาที่ร้อนเกินควรระวังการเพิ่มตู้ Plug-in / ตู้ Open

4.4 ตู้แช่ตาม BOQ (ข้อ 4) — หัวใจของแบบสำรวจ

ระบบสร้าง 1 การ์ดต่อ 1 รายการใน BOQ (เช่น "High Chilled glass door L2500 × 6") ป้ายมุมขวาบอกว่า BOQ วางแผนไว้อย่างไร ตรวจทุกใบในรายการนั้นแล้วแยกจำนวนตามผลจริง

4.5 Rack / Multiset / Cold room (ข้อ 5)

การ์ด Rack ใหม่ 2 ใบแรกได้ค่าตั้งต้นจากสัญญา PM (ใบที่ 1 = Positive · ใบที่ 2 = Negative: ยี่ห้อ / รุ่น · ปีติดตั้ง · น้ำยา · จำนวนคอมเพรสเซอร์) มีป้ายสีฟ้าบอกไว้ — ตรวจและแก้ตามที่เห็นจริงทุกช่อง

☁️ บันทึกทีละข้อ แล้วกลับมาทำต่อ

  • ท้ายข้อ 2–8 มีแถบสถานะ + ปุ่ม ☁️ บันทึกส่วนนี้ (ข้อ N) — ✅ บันทึกแล้ว · ⚠️ มีแก้ไข/รูปใหม่ที่ยังไม่บันทึก · ⬜ ยังไม่บันทึก · รูปที่ขึ้นระบบแล้วมีเครื่องหมาย ☁️
  • กดบันทึกทีละข้อระหว่างเดินตรวจ — รูปทยอยส่งขึ้นระบบ ตอนกด Submit จะเร็วขึ้นและไม่เสี่ยงหลุด
  • กลับมาทำต่อ: เปิดแท็บ 🥩 FF Renovate → เลือกสาขาเดิม (ล็อกอินบัญชีเดิม หรือใส่เบอร์โทรเดิม) → แถบสีเขียว "พบแบบสำรวจที่บันทึกไว้" → กด 📂 โหลดทำต่อ — ข้อมูลและรูปกลับมาครบ (เก็บไว้ 45 วัน)
  • หลังกด Submit ระบบสร้างรหัสตู้ + QR อัตโนมัติ 1 รหัสต่อ 1 ตู้ (Refurbish / Workable / Request New — ตู้ "ไม่พบ" ไม่มีรหัส) เช่น FFR-111128-FRZ01-03 · HO พิมพ์ป้าย QR ไปติดตู้ ใช้ต่อในขั้นจัดซื้อ ส่งของ ติดตั้ง และตรวจรับงาน — สแกนแล้วเห็นข้อมูลตู้และสถานะงาน
  • ถ้ามีคนใช้งานพร้อมกันมาก ระบบจะลองบันทึก / ส่งซ้ำให้อัตโนมัติ (ขึ้นข้อความ "กำลังลองอีกครั้ง") — ถ้ายังไม่สำเร็จ ข้อมูลยังอยู่ในฟอร์ม รอสักครู่แล้วกดใหม่
ช่องบังคับก่อน Submit: รูปฟอร์มกระดาษที่ SGM ลงนาม (ข้อ 8) · ผู้ตรวจ / เบอร์ / ตำแหน่ง / วันที่ / สาขา · สถานะ Final Layout · อุณหภูมิ ≥ 3 จุด + รูป · ทุกการ์ดตู้: จำนวน, แยกจำนวนครบ, สภาพ 3 ด้าน, เหตุผล (ถ้าซื้อใหม่นอกแผน), ประเภทตัดจำหน่าย (ถ้ามี Request New), รูป · ทุกการ์ด Rack: ข้อเสนอ MTN + รูป Rack + รูป Condenser · คำถามหน้างาน 9 ข้อ + ข้อเสนอระบบ · 6.2 ชนิดระบบแอร์ · 6.3 ข้อจำกัดการติดตั้งครบ 6 ข้อ

5. กติกาแยกจำนวน Refurbish / Workable / Request New

ผลสรุปความหมายตัวอย่าง
🛠️ Refurbish ได้ปรับปรุงแล้วใช้ต่อได้จริง (เปลี่ยนคอยล์ / ฉนวน / ประตู / ไฟ / ทำสี)โครงสร้างแข็งแรง ระบบทำความเย็นยังทำอุณหภูมิได้ ขนาดตรง Layout ใหม่
✅ Workable (ใช้ต่อ)ใช้ต่อได้เลย ไม่ต้องทำอะไรตู้ค่อนข้างใหม่ สภาพดี ทั้ง 3 ด้าน
🆕 Request Newต้องซื้อใหม่ · ตู้เดิมรื้อออก → Write-off / ขายซากสนิมทะลุ คอยล์รั่ว อะไหล่เลิกผลิต หรือขนาดไม่ตรง Layout
⛔ ไม่พบ / ไม่มีตู้เดิมแผนระบุ แต่หน้างานไม่มีตู้นี้ (ถูกย้าย / ถอดไปแล้ว / เป็นจุดติดตั้งใหม่)— ใส่หมายเหตุ
เหตุผลที่ต้องซื้อใหม่ / Refurbish ไม่ได้
  • โครงสร้างผุ / สนิมทะลุ
  • ฉนวนเสื่อม / เหงื่อออก
  • คอยล์รั่ว / ตัน
  • ทำอุณหภูมิไม่ได้
  • อะไหล่เลิกผลิต
  • ซ่อมบ่อย / ค่าซ่อมสูง
  • ขนาดไม่ตรง Layout ใหม่
  • กระจก / ประตูเสียหาย
  • อื่นๆ
เคล็ดลับ
  • อย่าเลือก Request New เพราะ "BOQ บอกให้ซื้อ" — ถ้าตู้ยังดี ให้เลือก Workable หรือ Refurbish
  • ตู้ซ่อมบ่อย (ซ่อม CMS หลายครั้ง / ค่าซ่อมสูง) ใส่ตัวเลขไว้ — ช่วยยืนยันการซื้อใหม่
  • ตู้ใบที่เสียต่างจากใบอื่น ให้เขียนในหมายเหตุ เช่น "ตู้ 3 ใน 8 ตัวคอยล์รั่ว"

6. เกณฑ์ Rack / Multiset

ประเภทที่เลือกได้
  • Multiset Positive (Chill)
  • Multiset Negative (Frozen)
  • Condensing Unit (CDU)
  • Cold Room Positive
  • Cold Room Negative
ข้อมูลที่ทีมออกแบบใช้ตัดสินใจ
  • อายุ + ชนิดน้ำยา
  • คอมเพรสเซอร์ทำงาน / ทั้งหมด
  • คราบน้ำมัน / รั่ว · สภาพ Condenser
  • ซ่อม CMS 12 เดือน + ค่าซ่อม
  • กำลังสำรองรับตู้เพิ่ม
  • รูป Rack + Nameplate + Condenser
ข้อเสนอ MTNใช้เมื่อ
ใช้ต่อได้คอมเพรสเซอร์ทำงานครบ ไม่รั่ว ซ่อมไม่บ่อย มีกำลังพอรับตู้ตามแผน
Overhaul / ซ่อมใหญ่โครงสร้างยังดี แต่ต้องเปลี่ยนคอมเพรสเซอร์ / พัดลม Condenser / ชุดคอนโทรล หรืออุดรั่วใหญ่
เปลี่ยน Rack ใหม่อายุมาก (เช่น > 15 ปี) + ซ่อมบ่อย / ค่าซ่อมสูง / น้ำยาเลิกใช้ (R22, R404A) / กำลังไม่พอรับตู้ใหม่

เกณฑ์ด้านบนเป็นแนวทางให้ MTN — การตัดสินใจเปลี่ยน Rack ขั้นสุดท้ายเป็นของทีมออกแบบ / จัดซื้อ จากรูปและข้อมูลในรายงาน

7. Remote หรือ Plug-in — ความพร้อมหน้างาน

8. Write-off & ขายซาก

ตู้ที่ใส่ Request New และ Rack ที่เสนอ เปลี่ยน = ของเดิมต้องรื้อออก แบบสำรวจนี้เก็บเฉพาะข้อมูลที่ต้องใช้ — การขอตัดจำหน่ายจริงทำในแอป MNC

  1. Asset No. (FAS) — ดูจากปุ่ม 📦 ทะเบียนทรัพย์สินสาขา (ในข้อ 2 ของฟอร์ม) · หลายเลขคั่นด้วย , · ไม่ทราบให้เว้นว่าง
  2. ประเภทตัดจำหน่าย (บังคับเมื่อมี Request New): Full write-off / Partial write-off / ไม่ต้องตัดจำหน่าย
  3. รูปทุกใบ (ตู้ · Rack Multiset · Condenser Multiset) — ใช้ประกอบการตัดจำหน่ายและขายซาก

ปุ่ม 📝 ขอตัดจำหน่ายตาม DOA เปิดหน้าขอ Write-off ในแอป MNC — ไม่ต้องทำระหว่างสำรวจ

9. คำถามที่พบบ่อย

BOQ บอก 8 ใบ แต่หน้างานมี 6 ใบ?ใส่จำนวนที่ตรวจ = 8 แล้วแยก 2 ใบเป็น "ไม่พบ" (เขียนหมายเหตุ) — หรือถ้าตู้จริงต่างรุ่น ให้เพิ่มการ์ด "ตู้ที่พบ" แยก
ตู้เดียวกันแต่สภาพต่างกัน ทำอย่างไร?การ์ดเดียวแยกจำนวนได้ เช่น 6 ใบ = Refurbish 4 + Workable 1 + Request New 1 · ประเมินสภาพตามภาพรวมของรายการ และเขียนใบที่แย่ในหมายเหตุ
ไม่มีเครื่องวัดความชื้น?ใส่เฉพาะ °C ได้ (%RH เว้นว่าง) แต่ต้องวัดอย่างน้อย 3 จุดและแนบรูปเครื่องวัด
ไม่รู้ Asset No.?เว้นว่างได้ — แต่ต้องเลือกประเภทตัดจำหน่าย และถ่ายรูปตู้ / Nameplate ไว้ ทีม HO จับคู่กับทะเบียน FAS ภายหลัง
สาขานี้ไม่มี Rack (ตู้ Plug-in ทั้งหมด)?ไม่ต้องเพิ่มการ์ด Rack — ตอน Submit ระบบจะถามยืนยันว่าสาขาไม่มี Rack / Multiset / Cold room
ส่งไปแล้ว อยากแก้ไข?ส่งแบบสำรวจของสาขาเดิมใหม่ได้ — รายงานใช้รายการล่าสุดของแต่ละสาขาเสมอ · รายการเก่าที่ส่งผิดให้แจ้ง Admin ลบ
ขึ้น 🔒 "เปิดได้เฉพาะ AMM MTN ของสาขาและทีม HO"?ไฟล์ Layout เป็นความลับของโครงการ — ขอดูจาก AMM MTN ตอนลงพื้นที่ แล้วเลือกสถานะ Final Layout ตามที่เห็น · ถ้าคุณเป็น AMM MTN ของสาขานั้นแต่ยังขึ้น 🔒 ให้แจ้ง HO ตรวจอีเมลในฐานข้อมูล
SGM ไม่อยู่สาขาวันที่ตรวจ ยังไม่ได้ลายเซ็น?กรอกทุกข้อแล้วกด Save Draft ไว้ก่อน — เมื่อ SGM ลงนามแล้วจึงถ่ายรูปฟอร์ม แนบในข้อ 8 แล้วกด Submit (ทำต่อจากเครื่องอื่นได้)
ไม่เห็นไฟล์ Final Layout ของสาขา?เลือก "ยังไม่ได้รับ Final Layout" แล้วตรวจต่อ · แจ้ง HO ให้วางไฟล์ในโฟลเดอร์ Layout และกดสแกน
