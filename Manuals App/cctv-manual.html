คู่มือแบบสำรวจคำขอ
กล้องวงจรปิด (CCTV)
สาขาแจ้งจุดที่ต้องการ → LP / Area คัดกรองจากรูปหน้างาน → เหลือเฉพาะ Must have ที่ช่วยลด Shrink เข้าคำของบ
👷 ผู้แจ้ง (ผจก.สาขา / M1)เมนู 📹 กล้องวงจรปิด (CCTV) ในหน้าแบบสำรวจ → กรอกกล้องปัจจุบัน + Shrink → เพิ่มการ์ดทีละจุด พร้อมรูป
🛡️ ผู้คัดกรอง (LP / Area / Admin)หน้า รายงาน CCTV → เปิดสาขา → ใส่ผลคัดกรองรายจุด (อนุมัติ / ลดจำนวน / ตัด / รอข้อมูล)
💰 งบประมาณประมาณ 33,000 ฿ / จุด รวมระบบ + ติดตั้ง (ราคาจริงขึ้นกับความสูง ระยะเดินสาย และเวลาทำงานกลางคืน)
🎯 หลักการไม่อนุมัติตามจำนวนที่ขอ — ทุกจุดต้องตอบได้ว่า ป้องกันความเสี่ยงอะไร และมีกล้องเดิมครอบคลุมหรือยัง

1. ทำไมต้องคัดกรอง

  • คำขอเพิ่มจากสาขารอบแรกมีราว 2,300 ตัว (Hyper ~1,500 · อื่นๆ ~800) — ถ้าอนุมัติทั้งหมดจะใช้งบเพิ่มประมาณ 150 ล้านบาท
  • เป้าหมายองค์กร: ลด Shrink ให้เหลือ 1.2 – 1.3% → กล้องต้องเป็นเครื่องมือลด Loss ไม่ใช่ติดตามคำขอแบบกว้างๆ
  • คำของบยังต้องผ่านการกลั่นกรองรอบถัดไป ส่งเฉพาะ Must have ที่มีข้อมูลรองรับ
  • กล้องเสีย แยกเรื่องจากการเพิ่มกล้องใหม่ — ให้เลือกประเภท "ทดแทนกล้องเสีย" หรือแจ้งในหัวข้อ 4
⭐ จุดเสี่ยงหลักที่ LP ให้ความสำคัญ (ขึ้นกลุ่มแรกในรายการพื้นที่):
1) จุดรับสินค้า Receiving / PR — ควรมี ≥ 2 กล้อง ไม่ใช่ตัวเดียวที่หันไป Loading B2B
2) Backroom / ทางเดินหลังร้าน / Stockroom — จุดซ่อน / เคลื่อนย้ายสินค้าโดยไม่ถูกบันทึก
3) SBA (ตาเขียว) / HBA — พบความเสี่ยงบ่อย
4) Cashier / ช่องทางออก — ภาพต่อเนื่องของลูกค้าที่ถือสินค้าออก (ส่งให้ Command Center ติดตามได้)

2. วิธีกรอกแบบสำรวจ (ผู้แจ้ง)

1เปิดแท็บ 📹 กล้องวงจรปิด (CCTV)

เข้าสู่ระบบ → เลือกแท็บ 📹 กล้องวงจรปิด (CCTV) → กรอก ชื่อผู้แจ้ง + เบอร์โทร → พิมพ์รหัส / ชื่อสาขาแล้วเลือกจากรายการ (ใช้ได้ทุก Format: Hyper, Mini, Market ฯลฯ)

อีเมล DM / CM จะถูกเติมให้อัตโนมัติในช่อง CC

2กล้องปัจจุบัน & Shrink ของสาขา

ช่องกรอกอะไร
กล้อง Online / Analog-Offline / เสีย *จำนวนกล้องทั้งสาขา (ใส่ 0 ถ้าไม่มี)
ประตูเข้า-ออก / มีกล้องนับคนแล้วใช้ประเมินจุดที่ยังขาดกล้องนับคน
Shrink ปัจจุบัน (%) *% ของยอดขาย เช่น 1.35
Shrink Act 2026 (% / บาท)ตัวเลขจริงปี 2026
Shrink Estimate (% / บาท)คาดการณ์หลังติดกล้อง — ใช้ดูความคุ้มค่า
แผนกที่มีความเสี่ยงสูงเลือกได้หลายแผนก

3เพิ่มการ์ดจุดกล้อง (1 การ์ด = 1 ตำแหน่ง)

  • พื้นที่ / Zone * — กลุ่ม ⭐ จุดเสี่ยงหลักอยู่ด้านบน
  • ตำแหน่ง / จุดสังเกต * — เช่น "ประตูรับสินค้าฝั่งขวา มองเข้าโต๊ะตรวจรับ"
  • ประเภทคำขอ * — เพิ่มจุดใหม่ / ย้าย-ปรับมุมกล้องเดิม / ทดแทนกล้องเสีย
  • จำนวนกล้องที่ขอ * — ตำแหน่งเดียวกันต้องการ 2 ตัว ใส่ 2
  • กล้องเดิมที่จุดนี้ * — ไม่มีเลย / มีแต่มุมไม่เห็นจุดเสี่ยง / มีแต่เสีย / ครอบคลุมแล้ว (ขอเสริม)
  • ความเสี่ยงที่ป้องกัน * + แผนก + จำนวนเคสที่จุดนี้ใน 12 เดือน
  • ต้องการนับคน — เฉพาะประตูที่มีทิศทางเข้า-ออกชัดเจน (Food Court เข้าได้ 4 ทิศ ไม่เหมาะ)
  • เหตุผล * และ ความจำเป็น * Must have / Nice to have
📷 บังคับแนบรูปทุกจุด — ถ่าย ตำแหน่งที่จะติด + มุมที่ต้องการให้กล้องเห็น เพื่อให้ LP ตรวจได้ว่าครอบคลุมจุดเสี่ยงจริง

แถบสรุปด้านบนแสดง จำนวนจุด · กล้องที่ขอ · Must have · ⭐ จุดเสี่ยงหลัก · งบประมาณประมาณการ แบบ real-time

4กล้องเสีย / สรุป / ส่ง

หัวข้อ 4: กล้องเสียที่ต้องซ่อมทันที (แยกจากคำขอเพิ่ม) · หัวข้อ 5: สรุปความจำเป็นภาพรวม · กด 💾 Save Draft เพื่อทำต่อภายหลัง (เปิดต่อได้ทุกเครื่อง) → กด Submit

ต้องการแก้ไขจุดกล้องหลังส่งแล้ว → ส่งแบบสำรวจใหม่ (รายงานใช้รายการล่าสุดของสาขา) ผลคัดกรองของรายการเดิมจะไม่ย้ายตามมา

3. การคัดกรอง (LP / Area / Admin)

1เปิดรายงาน

ลิงก์ View All Reports ในแท็บ หรือ ?page=cctv_survey_report · ด้านบนมีการ์ดสรุป: สาขาที่ส่ง · กล้องที่ขอ (ใหม่ / ย้าย / ทดแทน) · Must have · ⭐ จุดเสี่ยงหลัก · งบตามคำขอ · ผ่านคัดกรอง

กรองได้ตาม Format · สถานะคัดกรอง · เฉพาะสาขาที่มี Must have · แท็บ 📍 สรุปตามพื้นที่ แสดงจำนวนสาขา / กล้องที่ขอ / ผ่านคัดกรอง แยกตาม Zone (เช่น Dry Food กี่สาขา กี่ตัว)

2คัดกรองรายจุด

คลิกสาขา → ดูรูป / เหตุผล / กล้องเดิมของแต่ละจุด → เลือกผล:

ผลความหมายจำนวนที่นับ
อนุมัติจำเป็น ช่วยลด Shrinkเต็มจำนวนที่ขอ
อนุมัติบางส่วน (ลดจำนวน)จำเป็นแต่ไม่ต้องเท่าที่ขอ *ต้องใส่เหตุผลตามที่กรอก
ตัดออกมีกล้องครอบคลุมแล้ว / Nice to have *ต้องใส่เหตุผล0
รอข้อมูลเพิ่มรูปไม่ชัด / ไม่มีเหตุผลรองรับ *ต้องใส่เหตุผล0 (ยังนับว่ายังไม่คัดกรอง)

ปุ่มลัด: อนุมัติทุกจุด Must have · ตัดทุกจุด Nice to have → ใส่ความเห็นรวม → ✔ บันทึกผลคัดกรอง

3Export

⬇ Export Excel ได้ 2 ชีท: Stores (รายสาขา + Shrink + สรุปคำขอ / อนุมัติ) และ Points (รายจุด + ผลคัดกรอง + ลิงก์รูป) — ใช้แนบคำของบรอบถัดไป

4. Checklist ก่อนกดส่ง

  • กรอกกล้องปัจจุบัน + Shrink ปัจจุบันครบ
  • ทุกจุดมีรูปตำแหน่ง + มุมกล้อง
  • ทุกจุดตอบได้ว่าป้องกันความเสี่ยงอะไร และกล้องเดิมยังไม่ครอบคลุม
  • แยกกล้องเสียออกจากคำขอเพิ่ม
  • เลือก Must have เฉพาะจุดที่จำเป็นจริง
