1. ทำไมต้องสำรวจ — บทเรียนจากเหตุเพลิงไหม้

ช่วง ต.ค.–พ.ย. 2569 เกิดเหตุ 3–4 ครั้งในเวลาประมาณ 2 สัปดาห์ — ห้องสต็อกใกล้ Fan Coil, ห้องเก็บของ, เหนือฝ้า (พระราม 4), บ้านบึง และพังงา

พังงา 27/10/69: สายไฟเดิมของอาคารอายุ ~16 ปี วางพาดบนโครง C-Line เหนือฝ้า ไม่มีท่อร้อยสาย จุดต่อสาย พันเทปอย่างเดียว (ไม่มี Box ไฟ / Wire Nut) ลัดวงจรแล้วลามเข้า ห้องเก็บอุปกรณ์แม่บ้านที่มีกระดาษชำระจำนวนมาก — อพยพทั้งสาขา บันไดเลื่อน ระบบไฟ และร้านค้าเช่า ~20 ร้านได้รับความเสียหาย และสาขามีสปริงเกอร์เฉพาะโรงภาพยนตร์ชั้น 2

2. ใครสำรวจ และเมื่อไร

  • MTN สาขา / Area MTN — สำรวจในแอปหลัก แท็บ 🧯 ป้องกันอัคคีภัย Hyper (อยู่ในตารางนัดส่ง Hyper เป็นโมดูลที่ 9)
  • ผู้รับเหมา — สำรวจผ่าน Vendor Portal เมนู 🧯 สำรวจอัคคีภัย (เห็นเฉพาะสาขาที่มีงานกับตน) ผลส่งเข้าระบบเดียวกัน และ MTN ต้องตรวจรับ (ดูข้อ 7)
  • รอบสำรวจ — ตามวันนัดใน 📅 Hyper Upload Schedule · ตรวจซ้ำ ตามระดับสีของสาขา (ข้อ 4)
  • ใช้เวลา — ประมาณ 1.5–3 ชม. ต่อสาขา (ขึ้นกับจำนวนตู้ไฟ / ร้านค้าเช่า) · เตรียม ไฟฉาย บันได สำหรับเปิดช่อง Service เหนือฝ้า และ เทปแดง-ดำ

4. ระดับความเสี่ยงของสาขา (สี) และนัดตรวจซ้ำ

ระดับเงื่อนไขนัดตรวจซ้ำ (แนะนำ)
RED เสี่ยงสูง แก้ทันทีมีความเสี่ยง ระดับสูง ที่ยังไม่แก้ หรือ ตู้ FCP มี Fault / ปั๊มดับเพลิงไม่พร้อม / ทางหนีไฟถูกกีดขวางภายใน 7 วัน
ORG ต้องแก้ไขมีความเสี่ยง ระดับกลาง ที่ยังไม่แก้ หรือ ระบบป้องกันมีช่องว่าง (เช่น ไม่มีสปริงเกอร์ ถังดับเพลิงหมดอายุ)ภายใน 14 วัน
YEL เฝ้าระวังมีเฉพาะความเสี่ยงระดับต่ำ / ลดความเสี่ยงชั่วคราว ที่ยังค้างภายใน 30 วัน
GRE ปลอดภัยไม่มีความเสี่ยงค้างภายใน 30 วัน

ความเสี่ยงที่เลือกสถานะ “ลดความเสี่ยงชั่วคราว” ยังนับเป็นค้าง แต่ไม่ทำให้สาขาเป็นสีแดง/ส้ม — ต้องกลับมาแก้ถาวรในการตรวจซ้ำ

8. รายการตรวจทั้งหมด (14 พื้นที่)

● = จุดวิกฤต (พบความเสี่ยง → ระดับสูงอัตโนมัติ) · 🟥⬛ = พื้นที่ที่ควรตีเทปแดง-ดำ · ＋ = มีได้หลายจุด

⚡ 1. ห้อง MDB / หม้อแปลง / Generator 🟥⬛ (9 ข้อ)
  1. ● หน้าตู้ / ทางเข้าห้องโล่ง ไม่มีสิ่งของวางกีดขวาง (≥ 1 ม.)
  2. ● ไม่ใช้ห้องไฟฟ้าเป็นที่เก็บของ / กล่อง / สารเคมี
  3. ● ไม่มีกลิ่นไหม้ / รอยไหม้ / เสียงอาร์ค / ความร้อนผิดปกติที่ตู้และจุดต่อ
  4. ประตูห้องปิด-ล็อกได้ มีป้ายเตือนอันตราย / ห้ามเข้า
  5. ภายในห้องและตู้สะอาด ไม่มีฝุ่น หยากไย่ สัตว์ / น้ำรั่วซึม
  6. เบรกเกอร์มีป้ายระบุวงจรครบ อ่านออก
  7. มีผล Thermoscan ล่าสุด ≤ 1 ปี และแก้จุดร้อนแล้ว
  8. Generator / ถังน้ำมัน: ไม่มีน้ำมันรั่ว ไม่มีวัสดุติดไฟใกล้ ทดสอบเดินเครื่องตามรอบ
  9. มีถังดับเพลิง CO₂ / Clean Agent หน้าห้อง พร้อมใช้
🔌 2. ตู้ไฟย่อย (DB / LP) พื้นที่ขาย · หลังร้าน · Town Center 🟥⬛ ＋ (6 ข้อ)
  1. ● หน้าตู้โล่ง ไม่มีสินค้า / พาเลท / ชั้นวางกีดขวาง (≥ 1 ม.)
  2. ● ฝาตู้ปิดสนิท ล็อกได้ ไม่มีสายไฟโผล่ / รูเปิด
  3. ● ไม่มีกลิ่นไหม้ / รอยไหม้ / ความร้อนผิดปกติ
  4. สายเข้า-ออกตู้ร้อยท่อ / มีบุชชิ่ง ไม่ต่อพ่วงนอกตู้
  5. มีป้ายระบุวงจร / ตู้นี้จ่ายไฟพื้นที่ใด
  6. ภายในตู้ไม่มีฝุ่นหนา / ความชื้น / แมลง
🧵 3. เหนือฝ้า / รางเดินสายไฟ (เปิดช่อง Service ตรวจ) ＋ (7 ข้อ)
  1. ● สายไฟร้อยท่อ / วางในรางเรียบร้อย ไม่พาดบนโครง C-Line
  2. ● จุดต่อสายอยู่ใน Box ไฟ / ใช้ Wire Nut (ไม่ใช่พันเทปอย่างเดียว)
  3. ● ไม่พบสายเก่า ฉนวนกรอบ แตก ไหม้ / หนูกัด
  4. ● ไม่มีสินค้า / กล่อง / เศษวัสดุ / ขยะ เก็บบนฝ้า
  5. ไม่มีน้ำรั่วจากท่อ / หลังคา หยดใกล้สายไฟ
  6. มีช่อง Service เปิดตรวจได้ในจุดที่มีสายไฟผ่าน
  7. โคมไฟ / Ballast / Driver ไม่ร้อนจัด ไม่มีกลิ่นไหม้
📦 4. ห้องสต็อก / คลังหลังร้าน / ห้องเก็บของ (รวมจุดใกล้ Fan Coil) 🟥⬛ ＋ (7 ข้อ)
  1. ● สินค้าไวไฟ (กระดาษ กล่อง พลาสติก) ไม่วางชิดตู้ไฟ / Fan Coil / โคมไฟ / Heater
  2. ● เว้นระยะจากฝ้า / หัวสปริงเกอร์ ≥ 50 ซม. ไม่วางสูงจนติดฝ้า
  3. ● ไม่มีปลั๊กพ่วงต่อหลายทอด / อุปกรณ์ไฟฟ้าเสียบทิ้งไว้ / หม้อหุงข้าว
  4. Fan Coil ในห้อง: มอเตอร์ไม่ร้อน ถาดน้ำทิ้งไม่ล้น ไม่มีของวางทับ / อุดช่องลม
  5. ทางเดิน / ทางออกในห้องโล่ง ไม่มีสินค้าล้นกีดขวาง
  6. ผนัง / ฝ้าห้องไม่ใช่วัสดุติดไฟง่าย (ไม้ / ผ้าใบ) หรือมีการป้องกัน
  7. มีถังดับเพลิงหน้าห้อง / ในห้อง เข้าถึงได้
🧻 5. ห้องแม่บ้าน / สารเคมี / กระดาษชำระ 🟥⬛ ＋ (5 ข้อ)
  1. ● ปริมาณกระดาษชำระ / กระดาษ ไม่เกินจำเป็น จัดเก็บเป็นระเบียบ
  2. ● สารเคมี / น้ำยาไวไฟแยกเก็บ ปิดฝา มีป้าย ไม่วางรวมกับกระดาษ
  3. เครื่องขัดพื้น / แบตเตอรี่ชาร์จบนพื้นที่ไม่ติดไฟ ไม่ชาร์จทิ้งไว้ข้ามคืน
  4. ● ไม่มีสายไฟ / ปลั๊กชำรุด หรือสายไฟเหนือฝ้าผ่านห้องโดยไม่ร้อยท่อ
  5. ผ้าเปื้อนน้ำมัน / ผ้าชุบน้ำยา ทิ้งในถังฝาปิด
❄️ 6. ห้องเย็น / ห้องแช่แข็ง / ห้องเครื่อง Rack & คอยล์ร้อน 🟥⬛ ＋ (7 ข้อ)
  1. ● สาย Heater ประตู / ท่อน้ำทิ้ง ไม่ชำรุด ไม่ร้อนผิดปกติ
  2. ● ตู้คอนโทรล / ตู้ไฟ Rack ปิดฝา ไม่มีของวางกีดขวาง ไม่มีรอยไหม้
  3. ● ผนังฉนวน (PU / EPS) ไม่ฉีกขาด สายไฟผ่านผนังร้อยท่อ / อุดช่อง
  4. ไม่มีกล่องกระดาษ / พาเลท / พลาสติกห่อสินค้า กองชิดคอยล์ร้อน / ตู้คอนโทรล
  5. พัดลม Evaporator / Condenser ไม่มีเสียงดัง กลิ่นไหม้
  6. ห้องเครื่อง Rack: ไม่มีน้ำมันคอมเพรสเซอร์รั่ว / คราบน้ำมันสะสม
  7. คอยล์ร้อน / ห้องเครื่องสะอาด ไม่มีฝุ่นหนา / เศษใบไม้
🍗 7. อาหารสด / ครัว (เบเกอรี่ ไก่ย่าง ของทอด Deli Hot Food) ＋ (7 ข้อ)
  1. ● เตาทอด / เตาอบ / ตู้อบไก่ ทำความสะอาดคราบน้ำมันประจำวัน
  2. ● Hood / ท่อดูดควัน / ฟิลเตอร์ไขมัน ล้างตามรอบ (มีบันทึก)
  3. ● แก๊ส: ถัง / สาย / หัวปรับ ไม่รั่ว มีวาล์วตัด ถังตั้งในที่โปร่ง
  4. ● ปลั๊ก / สายไฟเครื่องครัวไม่เปียก ไม่ชำรุด ไม่ต่อพ่วง
  5. ปิดเตา / อุปกรณ์ความร้อนทุกตัวหลังเลิกงาน (มีผู้รับผิดชอบเช็กปิด)
  6. มีถังดับเพลิงชนิด K / ผ้าห่มกันไฟ ใกล้เตาทอด
  7. บรรจุภัณฑ์ / กล่องกระดาษไม่วางใกล้เตา / Heater
🍜 8. Food Court / ร้านอาหารในศูนย์ ＋ (6 ข้อ)
  1. ● แก๊ส LPG ของร้าน: ถังไม่เกินที่อนุญาต สายไม่หมดอายุ มีวาล์วตัด / Gas Leak Detector
  2. ● Hood / ท่อดูดควันรวม ล้างคราบไขมันตามรอบ (มีบันทึก)
  3. ● เตา / หม้อทอด ไม่มีคราบน้ำมันสะสม ไม่ตั้งชิดผนังไม้ / ป้าย
  4. ไม่มีปลั๊กพ่วงต่อหลายทอด / สายไฟเปลือย บริเวณร้าน
  5. ร้านปิดแก๊ส / ไฟอุปกรณ์หลังปิดศูนย์ (มีการตรวจปิดร้าน)
  6. ถังดับเพลิง / ชนิด K ประจำโซน พร้อมใช้ พนักงานร้านใช้เป็น
🏬 9. Town Center / Plaza พื้นที่ส่วนกลาง (ทางเดิน ลิฟต์ บันไดเลื่อน) ＋ (6 ข้อ)
  1. ● ทางหนีไฟ / บันไดหนีไฟ โล่ง ประตูหนีไฟไม่ล็อก ไม่ค้ำเปิด
  2. ● ป้ายทางออก / ไฟฉุกเฉินติดสว่าง ทดสอบแล้ว
  3. ● ไม่มีไฟชั่วคราว / ปลั๊กพ่วงของบูธ Event / Promotion ที่ไม่ได้มาตรฐาน
  4. ห้องเครื่อง / หลุมบันไดเลื่อนสะอาด ไม่มีคราบน้ำมัน ฝุ่น เศษขยะ
  5. ของตกแต่ง / ป้าย / ผ้า ไม่บังหัวสปริงเกอร์ Smoke Detector หรือโคมไฟ
  6. ตู้ดับเพลิง (FHC) / ถังดับเพลิงในทางเดิน เข้าถึงได้ ไม่ถูกบัง
🏪 10. ร้านค้าเช่าขนาดใหญ่ (Anchor · โรงภาพยนตร์ · Power Buy · ร้านอาหารใหญ่) ＋ (7 ข้อ)
  1. ● ตู้ไฟของร้านปิดฝา หน้าตู้โล่ง ไม่ใช้เป็นที่เก็บของ
  2. ● ไม่มีปลั๊กพ่วงหลายทอด / สายไฟต่อเอง / เดินสายไม่ร้อยท่อ
  3. ● ไม่เก็บสต็อก / กล่องบนฝ้า หลังป้าย หรือชิดโคมไฟ
  4. ห้องสต็อกของร้าน: เว้นระยะจากฝ้า / ไฟ ไม่ล้นทางเดิน
  5. ป้ายไฟ / โคมไฟร้าน / Lightbox ไม่ร้อนผิดปกติ มีเบรกเกอร์แยก
  6. ปิดอุปกรณ์ไฟฟ้าที่ไม่จำเป็นหลังปิดร้าน (มีผู้รับผิดชอบ)
  7. มีถังดับเพลิงในร้าน ไม่หมดอายุ พนักงานใช้เป็น · มีผังอพยพ
🛍️ 11. ร้านค้าเช่าขนาดเล็ก (CL · Kiosk · Booth · ร้านมือถือ) ＋ (6 ข้อ)
  1. ● ไม่มีปลั๊กพ่วงต่อหลายทอด / ปลั๊กรางคุณภาพต่ำ / สายไฟลอดใต้พื้น-พรม
  2. ● ร้านมือถือ / Power Bank / แบตเตอรี่: ไม่ชาร์จทิ้งไว้ข้ามคืน ไม่วางทับกัน
  3. ● ไม่มีอุปกรณ์ความร้อน (กาต้มน้ำ เตาไฟฟ้า ไดร์) ใช้โดยไม่ได้รับอนุญาต
  4. ไม่เก็บสินค้า / กล่องใต้เคาน์เตอร์ชิดสายไฟ หรือบนฝ้า
  5. ป้ายไฟ / โคมไฟร้านไม่ร้อนจัด ติดตั้งมั่นคง
  6. ปิดไฟ / ถอดปลั๊กเมื่อปิดร้าน
🚚 12. ลานรับสินค้า · ชาร์จรถ Forklift / Reach Truck · ห้องขยะ · เครื่องอัดกล่อง 🟥⬛ (5 ข้อ)
  1. ● จุดชาร์จแบตรถยก: อากาศถ่ายเท ไม่มีกล่อง / พาเลทกองชิด มีป้ายห้ามสูบบุหรี่
  2. ● พาเลทไม้ / กล่องเปล่า / ฟิล์มยืด ไม่กองสูง ไม่ชิดผนังอาคาร / ตู้ไฟ
  3. ● ห้องขยะ / เครื่องอัดกล่องสะอาด ขยะไม่ล้น ไม่มีการเผาขยะ
  4. มีจุดสูบบุหรี่ที่กำหนด ห่างวัสดุติดไฟ ไม่พบก้นบุหรี่ในพื้นที่
  5. Dock Leveller / ประตูม้วน: ตู้ควบคุมไม่ชำรุด ไม่มีน้ำมันรั่ว
☀️ 13. หลังคา · Solar Rooftop · ห้อง AHU · Chiller Plant (5 ข้อ)
  1. ● Solar: DC Combiner / Inverter ไม่มีรอยไหม้ สาย DC ไม่ห้อย ไม่ชำรุด ขั้วต่อ MC4 แน่น
  2. ● ห้อง AHU / ห้องเครื่อง ไม่ใช้เก็บของ มอเตอร์ / ตู้ไฟไม่ร้อนผิดปกติ
  3. หลังคา / รางน้ำ ไม่มีขยะ ใบไม้ กล่อง สะสม
  4. Chiller / Cooling Tower: ตู้ไฟปิดฝา ไม่มีน้ำมัน / สารทำความเย็นรั่ว
  5. ทางขึ้นหลังคาปิดล็อก มีป้ายเตือน และเข้าถึงได้เมื่อฉุกเฉิน
🅿️ 14. ภายนอกอาคาร · ป้าย Pylon · ลานจอดรถ · ถังแก๊ส LPG · EV Charger (5 ข้อ)
  1. ● ป้าย Pylon / ป้ายไฟหน้าอาคาร: ตู้ไฟ / Driver ไม่ชำรุด ไม่มีรอยไหม้
  2. ● ถังแก๊ส LPG / Manifold: มีรั้วกั้น ป้ายห้ามสูบบุหรี่ ห่างท่อระบายน้ำ / ประตู
  3. EV Charger: ตู้ไฟ / หัวชาร์จไม่ชำรุด มีเบรกเกอร์กันดูด ไม่มีของกองชิด
  4. ไม่มีหญ้าแห้ง / ขยะกองใกล้อาคาร หม้อแปลง หรือถังแก๊ส
  5. ทางเข้ารถดับเพลิง / หัวรับน้ำดับเพลิง (Siamese) ไม่ถูกกีดขวาง

10. คำถามที่พบบ่อย

สาขาไม่มีพื้นที่บางประเภท เช่น Food Court / Solar ต้องทำอย่างไร?
ติ๊ก “ไม่มีพื้นที่นี้ในสาขา” ในการ์ดนั้น — ระบบไม่นับข้อในการ์ดนั้น
ตู้ไฟย่อยมี 20 ตู้ ต้องทำ 20 การ์ดไหม?
ทำการ์ดตามกลุ่มที่อยู่ใกล้กันได้ (เช่น “DB-1 ถึง DB-4 หลังร้าน”) แต่จุดที่พบความเสี่ยงควรแยกการ์ดเพื่อให้รูปและการติดตามชัดเจน
แก้ไม่ได้เพราะต้องใช้งบประมาณ (เช่น เดินสายไฟใหม่เหนือฝ้า / ติดตั้งสปริงเกอร์)?
เลือก “ต้องของบประมาณ / แจ้ง HO” สถานะ “รอดำเนินการ” พร้อมกำหนดเสร็จที่คาดว่าจะได้งบ และสรุปในข้อ 6 ของฟอร์ม — รายงานนับรายการ “ของบ HO” แยกให้
เป็นความเสี่ยงของร้านค้าเช่า?
เลือก “แจ้งร้านค้าเช่าแก้ไข” ระบุชื่อร้านในช่องรายละเอียด และติดตามในการตรวจซ้ำ
ส่งไม่ได้ ขึ้นว่ายังไม่ได้ตอบข้อ…
ต้องตอบทุกข้อของทุกการ์ดที่มีพื้นที่จริง ระบบจะเลื่อนไปที่การ์ดที่ยังไม่ครบให้
รูปอัปโหลดไม่ผ่าน?
สัญญาณไม่เสถียร — ข้อมูลยังอยู่ กด Submit ซ้ำ รูปที่อัปโหลดแล้วไม่ต้องส่งใหม่ · หรือกด Save Draft แล้วทำต่อเมื่อสัญญาณดีขึ้น
ผู้รับเหมาเปิดลิงก์แล้วขึ้นว่าหมดอายุ?
ลิงก์ใช้ได้ 12 ชม. ให้กด 🧯 เปิดแบบสำรวจ ใน Vendor Portal ใหม่ · ถ้าไม่เห็นสาขาที่ควรเห็น แจ้ง MTN ของ Big C (ระบบอิงสาขาที่มีงาน CMS ของผู้รับเหมา)
