1. ระดับสิทธิ์ผู้ใช้

สิทธิ์อ่านจากคอลัมน์ Role และ Note ในชีต Employee_Database

ระดับตั้งค่าอย่างไรทำอะไรได้
Super Admin / AdminRole = admin หรือ Super Admin (ทั้งสองค่าเป็นสิทธิ์เดียวกัน)ทำได้ทุกอย่าง: แก้ไขแบบสำรวจทุกประเภท, Access Console, Data Archive, ล้างข้อมูลซ้ำ
System AdminRole = System Adminเปิดหน้าตั้งค่าได้ (Email, Users) แต่ไม่ได้สิทธิ์แก้แบบสำรวจอัตโนมัติ และไม่มีสิทธิ์ Data Archive
Survey / Schedule AdminRole = survey_admin หรือ schedule_adminแก้ไขแบบสำรวจได้ แต่ไม่ได้สิทธิ์ Admin เต็ม
SMF TeamNote = SMFตามสวิตช์ใน Access Console (ข้อ 2)
BF (Big Format)Note = BF / Big Formatใช้กับการจำกัดแท็บตามทีม (ข้อ 2)
Operationผู้ใช้ทั่วไปที่ล็อกอินตามสวิตช์ใน Access Console
💡 การเปลี่ยน Role ของผู้ใช้ทำในหน้า 👤 Manage Users (ลิงก์อยู่ท้าย Access Console) — ผู้ใช้ต้องออกจากระบบแล้วเข้าใหม่สิทธิ์ใหม่จึงมีผล

2. Access Console — สิทธิ์และสวิตช์

หน้าหลัก → ปุ่ม 🔐 Access Console (เปิดแท็บใหม่) ทุกการ์ดต้องกด Save Changes ของการ์ดนั้นจึงจะบันทึก

1📊 Role Access Matrix

สวิตช์ความหมายเมื่อเปิด
SMF → Full Admin Access (SMF_ADMIN_ENABLED)ทีม SMF ได้สิทธิ์เหมือน Super Admin ทุกอย่าง รวมถึง Access Console และ Data Archive (Flush) — ใช้อย่างระวัง
SMF → Edit Survey Data (SMF_SURVEY_EDIT_ENABLED_V1)SMF แก้ไขข้อมูลในหน้ารายงาน Ref / NP / Aircon / EDMI / Layout / Trading Hours ได้ (รวมการผูก Asset No.)
Operation → Edit Survey Data (OPS_SURVEY_EDIT_ENABLED_V1)ผู้ใช้ทั่วไปทุกคนแก้ไขข้อมูลแบบสำรวจได้

2👁️ Tab Visibility & Team Restriction

  • Default landing tab — แท็บที่เปิดขึ้นมาก่อนเมื่อผู้ใช้ทั่วไปล็อกอิน
  • Visible to general users — ซ่อน / แสดงแท็บแบบสำรวจสำหรับผู้ใช้ที่ไม่ใช่ Admin
  • Restricted to team — ล็อกแท็บให้เห็นเฉพาะทีม SMF, MMS หรือ BF

3📷 Equipment Photo Required

ติ๊กแบบสำรวจที่ต้องการบังคับแนบรูปอุปกรณ์ก่อนส่ง (ค่าเริ่มต้น = ไม่บังคับ)

4⚙️ Other Toggles

"Continue as Guest" — ปิดเมื่อต้องการให้ทุกคนต้องล็อกอินก่อนใช้งาน (บันทึกทันทีเมื่อกด ไม่ต้องกด Save)

3. Data Archive — ย้ายข้อมูลเก่าไป Drive

ทุกหน้ารายงานอ่านข้อมูลทั้งชีตทุกครั้งที่เปิด ชีตที่มีแต่เพิ่มแถวจึงช้าลงเรื่อยๆ Data Archive จะย้ายแถวที่เก่ากว่าระยะเวลาที่กำหนดออกจาก Google Sheet หลัก ไปเก็บในไฟล์ "Archive YYYY-MM" ในโฟลเดอร์ Drive "Air Ref Survey — Data Archive"

✅ ข้อมูลไม่ถูกลบทิ้ง — ระบบเขียนลงไฟล์ Archive แล้วนับแถวตรวจสอบก่อน จึงลบออกจากชีตหลัก ถ้าตรวจไม่ผ่านจะไม่ลบอะไรเลย

4. ขั้นตอนการ Flush ครั้งแรก

1เปิดการ์ด 🗄️ Data Archive

Access Console → เลื่อนลงไปที่การ์ด 🗄️ Data Archive (Flush to Google Drive) ตารางจะแสดงทุกชีต จำนวนแถวปัจจุบัน (Rows)

2ตั้งค่าและบันทึก

ติ๊ก / ไม่ติ๊กช่อง On และแก้ช่อง Keep (months) (ขั้นต่ำ 1 เดือน) → กด Save settings

3🔍 Preview (dry run)

กด Preview — ระบบนับอย่างเดียว ไม่ย้ายอะไร คอลัมน์ Will move จะแสดงจำนวนแถวที่จะถูกย้าย ตรวจว่าตัวเลขสมเหตุสมผล

ถ้าชีตไหนตัวเลข Will move สูงผิดปกติ (เช่น เกือบเท่า Rows) ให้หยุดและตรวจคอลัมน์วันที่ของชีตนั้นก่อน

4🗄️ Flush now

ปุ่มจะกดได้หลังจาก Preview แล้วเท่านั้น → กด → ยืนยัน → รอจนข้อความสถานะขึ้นว่าเสร็จ

  • หนึ่งรอบทำงานได้ราว 4.5 นาที ถ้าข้อมูลเยอะ หน้าจอจะทำต่อให้อัตโนมัติจนครบ — อย่าปิดหน้าต่างระหว่างทำงาน
  • ถ้าเผลอปิด ไม่เสียหาย — แถวที่ย้ายแล้วอยู่ใน Archive ครบ กด Preview → Flush now ใหม่เพื่อทำส่วนที่เหลือ
  • ระหว่าง Flush ผู้ใช้อื่นที่กำลังบันทึกแบบสำรวจอาจต้องรอไม่กี่วินาที (ระบบล็อกการเขียนทีละชีต) — แนะนำให้ทำนอกเวลางาน

5ตรวจผล

กด 📁 Open archive folder (มุมขวาบนของการ์ด) → เปิดไฟล์ Archive ของเดือนนี้ → แท็บ _Run_Log บันทึกวันเวลา ชีต และจำนวนแถวที่ย้ายในแต่ละรอบ บรรทัดล่างการ์ดแสดงผลรอบล่าสุด (Last run)

5. Auto-flush รายเดือน

ติ๊ก Auto-flush monthly (1st, 02:00) → ระบบจะ Flush เองทุกวันที่ 1 ของเดือน เวลา 02:00 ตามการตั้งค่าที่บันทึกไว้ ถ้าไม่เสร็จในรอบเดียวจะทำต่อเองอัตโนมัติ

💡 แนะนำ: Flush ด้วยมือ 1–2 ครั้งให้มั่นใจก่อน แล้วค่อยเปิด Auto-flush · ยกเลิกได้ทุกเมื่อโดยเอาติ๊กออก

6. 📦 ดูข้อมูลเก่าในรายงาน (Include archive)

ข้อมูลที่ย้ายไปแล้วจะไม่แสดงในรายงานตามปกติ ถ้าต้องการดู ให้กดปุ่ม 📦 Include archive ที่มุมซ้ายล่างของหน้ารายงาน → หน้าจะโหลดใหม่ มีแถบสีเหลือง "กำลังแสดงข้อมูลที่เก็บถาวรด้วย" และปุ่มเปลี่ยนเป็น 📦 Archive: ON กดอีกครั้งเพื่อปิด

มีปุ่ม 📦 (18 หน้า)ยังไม่มี (แสดงเฉพาะข้อมูลปัจจุบัน)
รายงาน Ref, NP, Aircon, EDMI, Layout, Trading Hours, CCTV · Hyper ทั้ง 7 (Ref, Aircon, Equipment, Fresh Food, Lighting, Toilet, Parking) · Work Order Report / Dashboard · Big C Work Order · Trip Plan Report / Map Survey Dashboard (คำนวณล่วงหน้า) · Broken Unit Summary · กราฟแนวโน้มรายเดือนรวม
  • อ่านอย่างเดียว — เปิดดูรายละเอียดได้ แต่แก้ไข / ลบไม่ได้ (จะขึ้นข้อความ "read-only" หรือ "Record not found")
  • ข้อมูลเก่าจะเรียงต่อท้ายข้อมูลปัจจุบัน
  • การเปิดครั้งแรกช้ากว่าปกติ (ต้องเปิดไฟล์ใน Drive) ครั้งต่อไปภายใน 6 ชั่วโมงจะเร็วขึ้น
  • ระบบจำการเลือกแยกต่อหน้าและต่อเครื่อง — ปิดเมื่อดูเสร็จ เพื่อให้หน้ารายงานกลับมาเร็วเหมือนเดิม
  • ปุ่มนี้ทุกคนที่เปิดรายงานได้ก็กดได้ — สิทธิ์การมองเห็นข้อมูลยังเป็นไปตามสิทธิ์เดิมของหน้านั้น

7. ไฟล์ Archive ใน Drive

  • โฟลเดอร์ "Air Ref Survey — Data Archive" อยู่ใน Drive ของบัญชีเจ้าของสคริปต์
  • หนึ่งไฟล์ต่อเดือนที่ทำการ Flush (ไม่ใช่เดือนของข้อมูล) เช่น Flush วันที่ 1 พ.ย. 2026 → ข้อมูลทุกปีที่ย้ายรอบนั้นอยู่ในไฟล์ Archive 2026-11
  • ในไฟล์มีหนึ่งแท็บต่อชีตต้นทาง (ชื่อเดียวกัน) + แท็บ _Run_Log
🚫 ห้ามเปลี่ยนชื่อไฟล์ Archive, เปลี่ยนชื่อแท็บ, ย้ายไฟล์ออกจากโฟลเดอร์ หรือลบหัวคอลัมน์ — ปุ่ม 📦 ในรายงานหาข้อมูลจากชื่อไฟล์ "Archive YYYY-MM" และชื่อแท็บ ถ้าเปลี่ยน ข้อมูลเก่าจะหายจากรายงาน (แต่ยังอยู่ในไฟล์)

ต้องการนำแถวกลับมาเป็นข้อมูลปัจจุบัน (Restore)

ยังไม่มีปุ่ม Restore — ให้ทำด้วยมือ: เปิดไฟล์ Archive → คัดลอกแถว → วางต่อท้ายชีตเดียวกันในไฟล์หลัก โดยเรียงคอลัมน์ให้ตรงกับหัวตารางของชีตหลัก → ลบแถวนั้นออกจากไฟล์ Archive (ไม่เช่นนั้นจะแสดงซ้ำเมื่อเปิด 📦)

ถ้าไม่ต้องการให้ชีตนั้นถูกย้ายอีก ให้ปิด On หรือเพิ่มจำนวนเดือนใน Data Archive ก่อน

8. 🗑️ ล้างข้อมูลซ้ำ (Duplicate Cleanup)

ในหน้ารายงาน Ref, Aircon, EDMI, Layout, Trading Hours มีปุ่ม 🗑️ ตรวจสอบข้อมูลซ้ำ (เห็นเฉพาะ Super Admin หรือ System Admin / SMF ถ้าเปิดสิทธิ์ไว้)

  1. กดปุ่ม → ระบบแสดงสาขาที่มีมากกว่า 1 แถว (แยกตามรอบ / วันที่ / โครงการ / Stage ตามประเภท)
  2. กด 🗑️ เก็บล่าสุด (รวมข้อมูล) ทีละสาขา → ระบบสำรองทุกแถวไว้ในแท็บ *_DupBackup → รวมข้อมูลและรูปจากทุกแถวเข้าแถวล่าสุด → ลบแถวที่ซ้ำ
  3. แท็บสำรองจะถูกย้ายไป Drive อัตโนมัติในการ Flush ครั้งถัดไป (กฎ Backups)

10. Checklist ประจำเดือน

  • ตรวจรายชื่อ Super Admin / System Admin ใน Manage Users — ถอดสิทธิ์คนที่ย้ายงานแล้ว
  • ตรวจสวิตช์ใน Role Access Matrix ว่ายังตรงกับนโยบาย (โดยเฉพาะ SMF Full Admin)
  • หลังวันที่ 1: เปิด Access Console ดูบรรทัด Last run ของ Data Archive ว่ารอบอัตโนมัติทำงานสำเร็จ
  • เปิด _Run_Log ในไฟล์ Archive ล่าสุด ดูว่าไม่มีชีตที่ขึ้น error
  • ทดลองเปิดรายงาน 1 หน้าพร้อม 📦 Include archive ว่าข้อมูลเก่ายังแสดง แล้วปิดกลับ

11. ปัญหาที่พบบ่อย

อาการสาเหตุ / วิธีแก้
ผู้ใช้แจ้งว่า "ข้อมูลเก่าหาย" ในรายงานน่าจะถูก Flush ไปแล้ว → ให้กด 📦 Include archive มุมซ้ายล่าง
ปุ่ม Flush now กดไม่ได้ต้องกด Preview ก่อนทุกครั้ง
ขึ้น "Super Admin privileges required"บัญชีนี้ไม่ใช่ Admin / Super Admin — ตรวจ Role แล้วออกจากระบบ / เข้าใหม่
เปิด 📦 แล้วไม่เห็นข้อมูลที่เพิ่งแก้ในไฟล์ Archiveระบบจำข้อมูล Archive ไว้ 6 ชั่วโมง — รอ หรือ Flush รอบถัดไปจะรีเฟรชให้
