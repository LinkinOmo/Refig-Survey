📱 เปิดแอป (แท็บ 🌬️ เครื่องเป่ามือ Hyper) 📊 รายงาน
1. แบบสำรวจนี้ใช้ทำอะไร 2. ก่อนเริ่ม — สิ่งที่ต้องเตรียม 3. ขั้นตอนสำรวจในแอป (ทีละขั้น) 4. ความหมายของตัวเลือก 5. ความปลอดภัย — สิ่งที่ต้องทำทันที 6. รายงาน 7. คำถามที่พบบ่อย

1. แบบสำรวจนี้ใช้ทำอะไร

แบบสำรวจห้องน้ำ 🚻 เดิมนับเครื่องเป่ามือแค่ จำนวน / จำนวนที่เสีย ต่อห้อง — แบบสำรวจนี้เก็บ ทีละเครื่อง เพื่อวางแผนซ่อม เปลี่ยน และติดตั้งเพิ่ม พร้อมตรวจความปลอดภัยไฟฟ้า:

ได้ข้อมูลอะไรทุกเครื่องในห้องน้ำลูกค้า + พนักงาน: ตำแหน่ง · ยี่ห้อ / ประเภท / กำลังไฟ / ปีที่ติดตั้ง · สถานะเมื่อกดใช้งานจริง · อาการ · สภาพ + ความสะอาด · มี RCD หรือไม่ · สิ่งที่ควรทำ + งบประมาณ
ผลที่ได้รายงานรวมทุกสาขา: เครื่องเสีย / มีปัญหา · จุดที่ควรติดตั้งเพิ่ม · เครื่องที่ไม่มี RCD · งบซ่อม / เปลี่ยนรวม · Export Excel ระดับเครื่อง
เวลาที่ใช้ประมาณ 2–3 นาที / เครื่อง (สาขาใหญ่ 15–25 เครื่อง ≈ 45–60 นาที)

2. ก่อนเริ่ม — สิ่งที่ต้องเตรียม

  • มือถือ + อินเทอร์เน็ต (สัญญาณไม่ดีให้กด 💾 Save Draft ไว้ก่อน)
  • รายชื่อ / ผังห้องน้ำทุกจุดของสาขา (ลูกค้า: พื้นที่ขาย, Town Center, Food Court · พนักงาน: หลังร้าน)
  • ไฟฉาย — อ่านป้าย Nameplate (ยี่ห้อ / รุ่น / W) ด้านข้างหรือใต้เครื่อง
  • ประสานช่างสาขา เพื่อดู ตู้ไฟ / เบรกเกอร์ วงจรห้องน้ำว่ามี RCD (กันดูด) หรือไม่

3. ขั้นตอนสำรวจในแอป (ทีละขั้น)

1เปิดแท็บ 🌬️ เครื่องเป่ามือ Hyper แล้วเลือกสาขา

  • Login → เลื่อนแถบแท็บไปทางขวา → 🌬️ เครื่องเป่ามือ Hyper
  • กรอกชื่อ + เบอร์โทร แล้วพิมพ์ รหัสสาขา 6 หลัก (เช่น 111123) หรือชื่อสาขา เลือกจากรายการ
  • แถบสรุปด้านบนจะนับ เครื่อง · ปกติ · มีปัญหา · เสีย · ไม่มีเครื่อง · งบประมาณ ให้ตลอดเวลา

2การ์ดทีละเครื่อง — ตำแหน่ง + ทดลองใช้งานจริง

  • 1 การ์ด = 1 เครื่อง (รหัสอัตโนมัติ สาขา-HB01, HB02 …)
  • ระบุ ตำแหน่ง (เช่น “ห้องน้ำหญิง Food Court”) · โซน · ห้องน้ำ (ชาย / หญิง / ผู้พิการ / พนักงาน) · ชั้น
  • เอามือเข้าไปกดใช้งานจริงทุกเครื่อง แล้วเลือกสถานะ — ป้ายบนหัวการ์ดเปลี่ยนสีตามสถานะ

3ข้อมูลเครื่อง + อาการที่พบ

  • ยี่ห้อ (ไม่มีในรายการ เลือก “อื่นๆ” แล้วพิมพ์) · รุ่น · ประเภท · กำลังไฟ W · ปีที่ติดตั้ง · Asset No.
  • ปีที่ติดตั้งใส่ ค.ศ. — ถ้าเผลอใส่ พ.ศ. (เช่น 2560) ระบบแปลงให้อัตโนมัติ
  • เครื่อง มีปัญหา / เสีย ต้องติ๊กอาการอย่างน้อย 1 ข้อ
💡 ประเภท Jet (สอดมือลง / ใบมีดลม) แห้งเร็วและกินไฟต่อครั้งน้อยกว่า ลมร้อน — รายงานแยกนับให้ เพื่อวางแผนเปลี่ยน

4ให้คะแนน · RCD · สิ่งที่ควรทำ · รูปถ่าย

  • แตะคะแนน 0–5: สภาพเครื่อง / แรงลม และ ความสะอาด / ถาดรองน้ำ / ไส้กรอง
  • RCD ของวงจรนี้: มี / ไม่มี / ไม่ทราบ (ดูที่ตู้ไฟร่วมกับช่างสาขา)
  • เลือก ควรดำเนินการ + ความเร่งด่วน + งบประมาณ (ถ้าทราบ)
  • ถ่ายรูป ตัวเครื่อง + ป้าย Nameplate

5เพิ่มเครื่องถัดไปเร็วๆ + จุดที่ “ไม่มีเครื่อง”

  • ⧉ เพิ่มเครื่องรุ่นเดียวกัน — คัดลอกตำแหน่ง / ยี่ห้อ / รุ่น / ประเภท / W / ปี / RCD จากเครื่องล่าสุด (สถานะ คะแนน รูป ต้องกรอกใหม่)
  • ห้องน้ำที่ ควรมีแต่ไม่มีเครื่อง: เพิ่มการ์ด เลือกสถานะ “ไม่มีเครื่อง (ควรติดตั้ง)” — ช่องข้อมูลเครื่องจะหายไป และตั้ง “ติดตั้งเพิ่ม” ให้

6ตรวจสรุปทั้งสาขา แล้ว Submit

  • ข้อ 3 สรุป ประเภท × สถานะ + kW รวม + จำนวนที่ต้องซ่อม / เปลี่ยน / ติดตั้งเพิ่ม และเตือน เครื่องที่ไม่มี RCD
  • ถ้ามีจุดอันตราย (กลิ่นไหม้, สายไฟเปลือย) ตอบ “มี” ในข้อ 4 แล้วระบุ
  • กด Submit — ระบบส่งอีเมลสรุปให้ผู้แจ้ง + CC

4. ความหมายของตัวเลือก

5. ความปลอดภัย — สิ่งที่ต้องทำทันที

⚡ กลิ่นไหม้ / ตัวเครื่องร้อนผิดปกติ / สายไฟเปลือย / ปลั๊กละลาย: หยุดใช้งาน แจ้งช่างสาขา ตัดไฟวงจรนั้นทันที ติดป้าย “ห้ามใช้” แล้วตอบ “มี” ในข้อ 4 จุดอันตราย พร้อมเลือกความเร่งด่วน “สูง”
🔌 ไม่มี RCD: เครื่องเป่ามืออยู่ในห้องน้ำซึ่งเปียกน้ำ — วงจรควรมีเบรกเกอร์กันดูด (RCD / ELCB) ทุกจุด รายงานจะรวมจำนวนเครื่องที่ไม่มี RCD ไว้เพื่อวางแผนติดตั้ง

6. รายงาน

  • การ์ดสรุป: สาขาที่สำรวจแล้ว · เครื่องที่ติดตั้ง / ใช้งานได้ · เสีย / มีปัญหา · จุดที่ควรติดตั้งเพิ่ม · ไม่มี RCD · งบประมาณรวม
  • กรอง มีเครื่องเสีย / ไม่มี RCD · คลิกแถวเพื่อดูทุกเครื่องพร้อมรูป · Export Excel ได้ทั้งระดับสาขาและระดับเครื่อง

7. คำถามที่พบบ่อย

คำถามคำตอบ
อ่านป้าย Nameplate ไม่ได้เลือกยี่ห้อ “ไม่มียี่ห้อ / ไม่ทราบ” เว้น W / ปีว่างได้ — ถ่ายรูปตัวเครื่องให้ชัด
เครื่องใช้ได้แต่ลมอ่อน / ถาดน้ำเต็มสถานะ “ใช้งานได้ แต่มีปัญหา” + ติ๊กอาการ + ดำเนินการ “ทำความสะอาด / PM” หรือ “ซ่อม”
ห้องน้ำมีเครื่อง 4 ตัวรุ่นเดียวกันกรอกเครื่องแรกให้ครบ แล้วกด ⧉ เพิ่มเครื่องรุ่นเดียวกัน อีก 3 ครั้ง
สำรวจซ้ำได้ไหมได้ รายงานใช้ รายการล่าสุด ของแต่ละสาขา — ส่งใหม่ทั้งชุดทุกครั้ง
แบบสำรวจห้องน้ำ 🚻 ยังต้องทำไหมทำตามปกติ — ห้องน้ำดูสภาพห้อง / สุขภัณฑ์ทั้งหมด, แบบนี้ดูเฉพาะเครื่องเป่ามือแบบละเอียดรายเครื่อง
