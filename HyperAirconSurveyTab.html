1. ข้อมูลสาขา (Branch Information)

รวม: AHU/FCU 0 แอร์ DX 0 พัดลม/ม่านอากาศ 0

🌡️ เครื่องมือวัดอุณหภูมิ (Temperature Instrument)

ค่าที่แสดงบนรีโมท / Chiller / BMS อาจไม่ตรงความจริง — วัดด้วยเครื่องมือ (เช่น Temp Gun) ที่ หน้ากากลมจ่าย (Supply) และ ช่องลมกลับ (Return) ของเครื่องแต่ละเครื่อง — ผลต่าง (ΔT) ปกติประมาณ 8–12°C

2. ระบบน้ำเย็น (Chiller Plant / AHU / FCU)

2.1) Chiller Plant (ห้องเครื่อง Chiller)

💡 ถ้าสาขาไม่มี Chiller (ใช้แอร์ DX ทั้งหมด) ให้เลือก "ไม่มี Chiller" แล้วข้ามไปข้อ 3

ใส่จำนวน Chiller / Cooling Tower / ปั๊ม แล้วระบบจะสร้างการ์ดทีละเครื่อง (Equipment ID + QR) ให้กรอกยี่ห้อ รุ่น ขนาด TR ปีที่ผลิต และถ่ายรูป

🌡️ น้ำเย็นจ่าย CHWS (°C) ปกติ ~6–7°C

🌡️ น้ำเย็นกลับ CHWR (°C) ปกติ ~12–13°C
