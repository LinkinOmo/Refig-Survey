ลืมรหัสผ่าน?

กรอกอีเมลหรือรหัสพนักงาน ระบบจะส่งลิงก์ตั้งรหัสผ่านใหม่ไปให้ทางอีเมล

📧

ส่งลิงก์แล้ว

หากอีเมลนี้มีอยู่ในระบบ คุณจะได้รับลิงก์สำหรับตั้งรหัสผ่านใหม่ภายในไม่กี่นาที (ลิงก์ใช้ได้ 30 นาที)

📖 คู่มือแบบสำรวจทั้งหมด

คู่มือนี้เน้นวิธีกรอกแบบฟอร์มหลักที่ผู้ใช้งานทั่วไปต้องกรอกเป็นประจำ — EDMI Solar Meter, เครื่องปรับอากาศ, ตู้แช่, New Product และ พื้นที่ก่อนติดตั้ง (Layout) — แต่ละแบบฟอร์มมีคู่มือฉบับเต็มแยกของตัวเอง กดปุ่มด้านล่างแต่ละหัวข้อเพื่อเปิดอ่าน

☀️ อ่านค่า EDMI Meter (Solar) — สรุปย่อ

  1. กรอกชื่อผู้แจ้ง แล้วค้นหา/เลือกสาขาด้วยรหัส 5 หลักหรือชื่อสาขา
  2. เลือกรูปแบบสาขา (Small Format (BCM) หรือ Big Format) และ Solar Phase
  3. ระบุวันที่และเวลาที่อ่านค่าจากมิเตอร์จริง
  4. กรอกค่าทั้ง 4 Code (000 Total, 001 Peak, 002 Off Peak, 003 Holiday) พร้อมถ่ายภาพหน้าจอมิเตอร์แนบทุก Code
  5. ตรวจสอบข้อมูลให้ครบถ้วนแล้วกด Submit
📄 เปิดคู่มือ EDMI Solar Meter ฉบับเต็ม (พร้อมตัวอย่างและวิธีพิมพ์)

❄️ แบบสำรวจเครื่องปรับอากาศ (แอร์) — สรุปย่อ

  1. กรอกชื่อผู้แจ้ง แล้วค้นหา/เลือกสาขาด้วยรหัส 5 หลักหรือชื่อสาขา
  2. กรอก จำนวนแอร์ทั้งหมด ในพื้นที่ขาย → ระบบสร้างการ์ดให้กรอกรายละเอียดทีละเครื่อง (ยี่ห้อ ประเภท สภาพเครื่อง ฯลฯ)
  3. ระบุว่ามีเครื่องชำรุดหรือไม่ หากมี ให้เลือกเครื่องที่ชำรุดและติ๊ก Checklist 5 หัวข้อ
  4. สรุปปัญหาเพิ่มเติม (ถ้ามี) แล้วกด Submit หรือ Save Draft
📄 เปิดคู่มือแอร์ฉบับเต็ม (ทีละขั้นตอน + เคล็ดลับ + FAQ)

🧊 แบบสำรวจตู้แช่ — สรุปย่อ

  1. กรอกชื่อผู้แจ้ง แล้วค้นหา/เลือกสาขา เช่นเดียวกับแบบสำรวจแอร์
  2. กรอกจำนวนตู้แต่ละประเภท: ตู้ OPEN, ตู้บานกระจก (Plugin/Walk-in/Remote), ตู้แช่แข็ง (Plugin/Remote/Walk-in), ตู้ไอศกรีม, ตู้น้ำแข็ง, ตู้ 4 ประตู Stainless — ใส่ 0 หากไม่มี
  3. ระบุว่ามีตู้ชำรุดหรือไม่ หากมี ให้เลือกตู้ที่ชำรุดและติ๊ก Checklist 10 หัวข้อ
  4. สรุปปัญหาเพิ่มเติม (ถ้ามี) แล้วกด Submit หรือ Save Draft
📄 เปิดคู่มือตู้แช่ฉบับเต็ม (ทีละขั้นตอน + เคล็ดลับ + FAQ)
💡 สำรวจอุปกรณ์ทุกตัวให้ครบก่อนเสมอ แล้วจึงค่อยเลือกเครื่อง/ตู้ที่ชำรุดในขั้นตอนถัดไป — ระบบจะดึงรายชื่อให้เลือกจากข้อมูลที่กรอกไว้ก่อนหน้าเท่านั้น

🍦 แบบสำรวจ New Product — สรุปย่อ

  1. กรอกชื่อผู้สำรวจ และเบอร์โทรศัพท์ (บังคับทั้งคู่) แล้วค้นหา/เลือกสาขา
  2. กรอกจำนวนเครื่องแต่ละหมวด: Soft Serve, Jet Spray, Slushy, Ice Maker, เครื่องกรองน้ำ — ใส่ 0 หากไม่มี
  3. ต่อเครื่อง 1 ตัว ต้องถ่ายรูป 3 อย่าง: 📷 ตัวเครื่อง, 🔌 ปลั๊กไฟ, 📍 บริเวณที่ติดตั้ง
  4. ระบุอุปกรณ์ชำรุด (ถ้ามี) พร้อมคำอธิบาย แล้วกด Submit หรือ Save Draft
📄 เปิดคู่มือ New Product ฉบับเต็ม

📐 แบบสำรวจพื้นที่ก่อนติดตั้ง (Layout) — สรุปย่อ

  1. ใช้เฉพาะสาขาที่อยู่ในโครงการ — กรอกผู้แจ้ง เบอร์โทร แล้วค้นหาสาขาจากรายการที่จำกัดไว้
  2. กรอกข้อมูลโครงการ: รูปแบบสาขา ชื่อโครงการ วันที่สำรวจ
  3. ตรวจ 3 ประเด็นหน้างาน: มีคานกีดขวางหรือไม่ / มีแอร์อยู่เหนือจุดติดตั้งหรือไม่ / อุปสรรคอื่น ๆ — พร้อมแนบภาพประกอบทุกข้อ
  4. กด Submit (แบบฟอร์มนี้ไม่มี Save Draft)
📄 เปิดคู่มือ Layout Survey ฉบับเต็ม

📖 คู่มือกรอกแบบฟอร์ม EDMI Solar Meter — พร้อมตัวอย่างและวิธีพิมพ์ →

💡 ถ่ายภาพหน้าจอ EDMI Meter ของระบบ Solar ตามวันที่กำหนด ช่วงเวลา 11.00-12.00 น. และส่งข้อมูลภายในเวลา 15.00 น. ของวันเดียวกัน

📋 ขั้นตอนการเก็บข้อมูลหน้างาน

  1. 1 ถ่ายภาพนิ่ง หน้าจอมิเตอร์ด้วยมือถือ ให้เห็น Code และตัวเลขชัดเจน ครบทั้ง 4 Code (000-003)
  2. 2 อัดวิดีโอ กดวนดูครบทุก Code ตั้งแต่ 000 ถึง 003 ในคลิปเดียว (ใช้เป็นหลักฐานสำรอง หากภาพนิ่งไม่ชัดหรือมีข้อโต้แย้งภายหลัง) — เก็บคลิปไว้ที่เครื่อง ไม่ต้องอัปโหลดเข้าแอป
  3. 3 กรอกตัวเลข ที่อ่านได้ลงในแบบฟอร์มด้านล่าง และอัปโหลดภาพถ่าย (จากข้อ 1) แนบทุก Code แล้วกด Submit

1. ข้อมูลสาขา (Branch Information)

2. ข้อมูลระบบ Solar (Solar System Info)

3. หน่วยไฟฟ้าจาก EDMI Meter (kWh) และภาพถ่ายหน้าจอ

⚠️ กรอก "ตัวเลขค่าไฟที่อ่านได้จากหน้าจอมิเตอร์จริง" เท่านั้น (ปกติเป็นเลขหลักพัน-หลักแสน เช่น 45231.50)

อย่ากรอก 0, 1, 2, 3 ตามชื่อ Code 000-003 — คำว่า "Code 000/001/002/003" เป็นแค่ชื่อเรียกช่องนั้นๆ ไม่ใช่ค่าที่ต้องกรอก

ค่าไฟทั้งหมดที่ติดตั้งมิเตอร์มา ทุกช่วงเวลา — กรอกเลขจากหน้าจอมิเตอร์

ยอดสะสมเฉพาะช่วง Peak (09.00-22.00 น.) — ไม่ใช่เวลาที่ต้องอ่านค่า อ่านได้ทุกเมื่อ — กรอกเลขจากหน้าจอมิเตอร์

ยอดสะสมเฉพาะช่วง Off Peak (22.00-09.00 น.) — ไม่ใช่เวลาที่ต้องอ่านค่า อ่านได้ทุกเมื่อ — กรอกเลขจากหน้าจอมิเตอร์

ยอดสะสมเฉพาะวันหยุด (เสาร์-อาทิตย์ และวันหยุด ตลอด 24 ชม.) — ไม่ใช่เวลาที่ต้องอ่านค่า อ่านได้ทุกเมื่อ — กรอกเลขจากหน้าจอมิเตอร์
