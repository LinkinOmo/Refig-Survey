1. ทำไมต้องตรวจ

สถานะวันนี้ (ไฟล์ LP ณ 10/11/2026): อุปกรณ์กลุ่ม "เสีย / รอซ่อม" 1,544 รายการ — กล้องวงจรปิด 738 · เครื่องทำลาย TAG 248 · เสา EAS 224 · UPS 187 · TV/Monitor 96 · Hard Disk 51

กล้อง 628 รายการ และเสา EAS อีกจำนวนมาก ติดสถานะ "รอยืนยัน — ให้ MTN สรุปว่าซ่อมได้หรือไม่ได้" ถ้า MTN สรุปได้ งานจะเดินต่อเข้า OPEX (ซ่อม) หรือ CAPEX ของ LP (ซื้อใหม่) ได้ทันที

ปัญหาที่พบจากการประชุม 10/11/2026:

  • ใบแจ้งซ่อมจำนวนมาก ถูกยกเลิกอัตโนมัติ เมื่อไม่อัปเดตภายใน 7 วัน — สถานะ "ยกเลิก" ไม่ได้แปลว่าซ่อมแล้ว
  • ข้อมูลสำรวจเดิมอาศัย LP ยืนยันฝ่ายเดียว ยังไม่มีใครยืนยันที่หน้างานว่า "ซ่อมได้" หรือ "ต้องซื้อใหม่"
  • ใบเสนอราคาไม่แยกค่าอุปกรณ์ออกจากค่าแรง / ค่าปีนป่าย / ค่าทดสอบ ทำให้จำแนก OPEX / CAPEX ยาก

หลักการ: ใช้แบบสำรวจนี้เป็น ฐานข้อมูลเดียว · ตรวจทุกรายการที่หน้างาน · เปิด CMS ใหม่เฉพาะรายการที่ต้องซ่อม / เปลี่ยนจริง (ไม่ใช้ CMS ชุดเดิมเป็นฐาน)

2. ภาพรวม 4 ขั้นตอน

1เลือกสาขาระบบดึงรายการเสียจาก LP + งาน CMS (CCTV / EAS) มาให้ และสร้างการ์ดอัตโนมัติ
2นับจริง + ตรวจเกณฑ์นับอุปกรณ์ที่หน้างาน · ตรวจ 11 ข้อ OK / NG
3แยกผลทุกการ์ดใช้ได้แล้ว / ซ่อมได้ / ต้องเปลี่ยนใหม่ / ไม่พบ + ค่าใช้จ่าย + รูป
4ส่ง → เปิด CMSเปิด CMS ใหม่เฉพาะที่ซ่อม/เปลี่ยน แล้วใส่เลข CMS ในรายงาน

3. ใครกรอก / เตรียมอะไร

  • ผู้กรอก: MTN สาขา, AMM / ทีม MTN หรือผู้รับเหมาที่เข้าตรวจ (เลือก "ผู้รับเหมา" แล้วใส่ชื่อบริษัท) — LP / Area LP ร่วมเดินตรวจได้
  • เตรียม: มือถือที่ล็อกอินแอป · เข้าห้อง CCTV ได้ · บันไดหรืออุปกรณ์ขึ้นที่สูง (ถ้าต้องดูตัวกล้อง) · Tag ทดสอบเสา EAS
  • เวลา: สาขา Hyper ประมาณ 1–2 ชม. · มินิบิ๊กซี 20–30 นาที · กด Save Draft ระหว่างทางได้ แล้วทำต่อจากเครื่องอื่น
  • ทุกสาขาที่มีรายการเสียในไฟล์ LP ต้องตรวจ · สาขาที่ไม่มีในไฟล์ LP แต่พบปัญหา ก็ส่งได้ (เพิ่มการ์ดเอง)

7. สาขาปิด — เก็บกู้อุปกรณ์

สาขาที่อยู่ในแผนปิด (เช่น 12 สาขา วันขายวันสุดท้าย 15/12/2026) ให้เลือกวัตถุประสงค์ "สาขาปิด — เก็บกู้อุปกรณ์" ระบบจะซ่อนข้อ 2–3 และแสดงตารางเก็บกู้แทน

  • ถอดเก็บของที่ยังใช้ได้ ก่อนผู้ซื้อซากเข้าพื้นที่ · สาขา Hyper มีประมาณ 100 ตัว · Market 30–40 ตัว
  • ส่งกลับ Warehouse ตลาดนิมิต เพื่อคัดแยกไปซ่อม/ขยายระบบสาขาอื่น · ของเสียนับแยก

8. เปิด CMS ใหม่ & ใส่เลข

  1. หลังส่งแบบสำรวจ เปิด CMS ใหม่ เฉพาะการ์ดที่มี "ซ่อมได้" หรือ "ต้องเปลี่ยนใหม่" (ระบุในรายละเอียด: เลขแบบสำรวจ CSYS + เลขการ์ด เช่น I01)
  2. เข้า รายงาน → คลิกสาขา → ใส่เลข CMS 9 หลักในแต่ละการ์ด → กด ✔ บันทึกเลข CMS
  3. ระบบจับคู่เลขกับ CMS Dashboard ให้อัตโนมัติ และแสดงสถานะ (ค้าง / ปิดงาน / ยกเลิก) — ถ้างานถูกยกเลิกแต่ยังไม่ซ่อม ให้เปิดเคสใหม่ตามขั้นตอนเดิมและบันทึกหมายเหตุ
  4. อัปเดตงานใน CMS อย่างน้อยทุก 7 วัน เพื่อไม่ให้ระบบยกเลิกอัตโนมัติ

11. คำถามที่พบบ่อย

LP ระบุกล้องเสีย 22 ตัว แต่หน้างานเจอเสีย 15 ตัว ทำอย่างไร?ใส่ในการ์ดเดิม: ใช้งานได้แล้ว 7 + แยกที่เหลือเป็น ซ่อมได้ / เปลี่ยนใหม่ ให้ครบ 22 · ถ้าเจอเสียเพิ่มนอกรายการ LP ให้กด "＋ เพิ่มอุปกรณ์ที่พบเสีย"
ยังไม่รู้ราคาซ่อม จะกรอกอย่างไร?ใส่วิธีซ่อมไว้ก่อน (บังคับ) ช่องราคาเว้นได้ · เมื่อผู้รับเหมาเสนอราคา ให้ส่งแบบสำรวจใหม่ของสาขา (รายงานใช้รายการล่าสุด) หรือแจ้ง AMM
การ์ดเดียวทั้งซ่อมและเปลี่ยนได้ไหม?ได้ — เช่น กล้อง 22 ตัว ซ่อม 12 (OPEX) เปลี่ยน 4 (CAPEX) ระบบคำนวณแยกให้
ทำไมต้องแยกค่าแรง ค่าปีนป่าย ค่าทดสอบ?เพื่อจำแนก OPEX / CAPEX ตามหลักบัญชี และตรวจใบเสนอราคาได้ — ค่าอุปกรณ์ที่เป็นทรัพย์สินใหม่อาจเป็น CAPEX แต่ค่าแรงไม่ใช่
CMS เดิมที่ LP อ้างขึ้น "ยกเลิก" ต้องทำอะไร?ถ้าตรวจแล้วอุปกรณ์ยังเสีย ให้เลือก ซ่อมได้ / เปลี่ยนใหม่ และเปิด CMS ใหม่ (ไม่ต้องพยายามเปิดเคสเดิม) แล้วใส่เลขใหม่ในรายงาน
สาขาของฉันไม่มีในไฟล์ LP?ยังส่งได้ — ไม่มีการ์ดอัตโนมัติ ให้เพิ่มการ์ดเองเฉพาะอุปกรณ์ที่เสีย หรือส่งโดยไม่มีการ์ดเพื่อยืนยันว่าระบบปกติ
