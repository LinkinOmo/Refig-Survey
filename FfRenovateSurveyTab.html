🎯 แนวทาง & Checklist สำหรับ M1 / Store MTN (อ่านก่อนลงพื้นที่)

เป้าหมาย: งบและเวลามีจำกัด — ต้องรู้ ของจริงหน้างาน ไม่ประเมินเกินหรือขาด ก่อนสรุป BOQ / จัดซื้อ

1. อุณหภูมิพื้นที่ขาย — วัดอย่างน้อย 3 จุด (Produce / Butchery / Frozen ...) ช่วงบ่ายที่ร้อนที่สุด สูง 1.5 ม. ห่างตู้ ≥ 1 ม. เกณฑ์ตู้ Class 3 = ≤ °C / ≤ %RH

2. ตู้แช่ตาม BOQ — ทุกการ์ดแยกจำนวนเป็น Refurbish (ปรับปรุงได้จริง) / Workable (ใช้ต่อได้ ไม่ต้องทำ) / Request New (ต้องซื้อใหม่) / ไม่พบ · ดูสภาพตัวตู้ ระบบทำความเย็น ประตู/กระจก + ประวัติซ่อม CMS 12 เดือน · ถ่ายรูปทุกการ์ด

3. Rack / Multiset / Cold room — รูป Rack ทั้งชุด + Nameplate + Condenser + ตู้คอนโทรล เพื่อให้คุณเต้ยตัดสินใจเปลี่ยน Rack หรือไม่

🧾 Write-off & ขายซาก — ตู้ / Rack ที่จะรื้อออก ใส่ Asset No. (FAS) + Full / Partial write-off และถ่ายรูปรอไว้ทุกใบ (ตู้แช่ · Rack Multiset · Condenser Multiset) ให้ GCP แจ้ง Supplier เสนอราคาซาก และ FAD ใช้ประกอบการขออนุมัติ CAPEX

4. Remote / Plug-in — หลักการ: ตู้กลางฟลอร์ = Plug-in · ตู้ริมผนัง Upright ที่มีระบบรองรับ = Remote · เช็กกำลังไฟ จุดระบายน้ำ แนวท่อ พื้นที่ห้องเครื่อง

⚡ แอร์ / ไฟ / การติดตั้ง — ถ่ายหน้าจอ Chiller หรือ BMS ช่วงบ่าย (โหลด % · เครื่องที่เดิน) · ขนาดหม้อแปลง + กระแสสูงสุด MDB · ทางขนตู้ / Loading / เวลาทำงานกลางคืน — ติดตั้งจริงต้องทำโดยไม่ปิดขาย

5. Final Layout — เทียบ Layout ล่าสุดกับหน้างาน (ดาวน์โหลดได้ในข้อ 2 หลังเลือกสาขา)

🗓️ 17 พ.ย. สื่อสาร Area MTN · 18–21 พ.ย. ลงพื้นที่ · 22 พ.ย. รวบรวม · 23 พ.ย. รายงานเข้าที่ประชุม

4. ตรวจตู้แช่ตาม BOQ (การ์ดทีละรายการ)

ระบบสร้างการ์ดจาก BOQ ให้แล้ว: แผน Refurbish = ตรวจว่าปรับปรุงได้จริงไหม · แผนซื้อใหม่ = ดูตู้เดิมที่จะถูกแทน ถ้ายังดีให้ใส่ Workable (ลดงบ) · ถ้าไม่มีตู้เดิม (ตู้เพิ่มใหม่) ใส่ "ไม่พบ" · แยกจำนวนให้ครบ · ต้องมีรูปทุกการ์ด
