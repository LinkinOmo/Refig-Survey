Chapter 2: Data Loading & Standardization

You cannot do math on messy text. The notebook uses Pandas to ingest lists and standardizes fields immediately using the assign and to_datetime methods.

Learning Point: .assign() creates a new column or safely overwrites an existing one. pd.to_datetime() forces dates into a universal mathematical format. If someone typed "Last Tuesday" instead of a real date, errors='coerce' handles the error gracefully by turning it into a blank NaT (Not a Time) instead of crashing Python.

Chapter 3: Connecting Disjointed Data (VLOOKUP)

Just like relational databases and Excel, you often have to match data lists. The notebook matches survey data against the active store list (master_active).

_dd_lu = master_active[['GOLD Code', 'DD Name (14)']].copy()
_dd_lu['GOLD Code'] = _dd_lu['GOLD Code'].astype(str).str.strip()

oc = oc.merge(_dd_lu.rename(columns={'GOLD Code':'_gkey'}),
              left_on='Store ID', right_on='_gkey', how='left')

Learning Point:

  • .astype(str) forces store IDs to be treated as text. This prevents weird errors where '0114' gets reduced to '114' mathematically.
  • .str.strip() is a lifesaver. It deletes any accidental invisible spaces around the store ID so that the match actually works.
  • .merge() is Python's ultra-fast version of VLOOKUP, gluing the table together where the Store ID matches the GOLD Code.

# Filling dimensions with Medians
fleet['extra_kwh'] = fleet['extra_kwh_sqm'] * fleet['Net sqm'].fillna(fleet['Net sqm'].median())

Learning Point: You don't want to fill missing store square-meters with "0" because that destroys your averages. fleet['Net sqm'].median() safely finds the middle size of all stores and quietly patches any missing data with that number.
