✉️ Email Delivery — Brevo Fallback

Configure the backup email channel used when the Gmail daily quota runs out

Back to App

When the Gmail daily quota (~100 recipients/day) is exhausted, app emails (survey notifications, work-order approvals, safety incidents…) are sent through the Brevo transactional API instead. The sender email must be a verified sender in your Brevo account.

Paste your xkeysib-… key. Leave blank to keep the saved key.

Testing aid — while ON, every email is queued straight to the local-Outlook outbox instead of trying Gmail/Brevo first. Turn OFF again after testing; leaving it on stops all real Gmail/Brevo delivery. If Outlook itself fails to send a queued email, it automatically falls back to Gmail/Brevo for real before giving up. Successfully sent rows are removed from the queue automatically — no manual cleanup needed.

Runs on Apps Script's own clock, independent of the local PC — if a genuinely-queued row is still "pending" after 15 min (e.g. the poller PC is off/asleep/task disabled), it retries Gmail then Brevo automatically instead of waiting forever. Requires the timer below to be installed once.

The API key is stored in this app's Script Properties only — never exposed to the browser after saving.
